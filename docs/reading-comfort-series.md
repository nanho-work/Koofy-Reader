# 독서 간격과 묶음 진행 안내

## 독서 설정

Android/iOS의 독서 설정에 줄간격·문단 간격·페이지 여백을 추가했다. 글꼴 목록은 계속 마지막에 둔다.

| 설정 | 선택값 | 저장 값 |
|---|---|---|
| 줄간격 | 기본 / 촘촘 / 보통 / 넉넉 | null / 1.2 / 1.5 / 1.8 |
| 문단 간격 | 기본 / 없음 / 보통 / 넓게 | null / 0 / 0.5 / 1.0 rem |
| 페이지 여백 | 기본 / 좁게 / 보통 / 넓게 | null / 0.5 / 1.0 / 1.5 배율 |

세 값은 기존 전역 독서 설정과 동일하게 모든 책에 적용되고 백업에도 포함된다. 구버전 설정/네이티브 복구 저널에 필드가 없으면 null로 읽어 기존 기본 배치를 유지한다. 별도 SQLite 스키마 변경은 없다.

Readium의 `lineHeight`, `paragraphSpacing`, `pageMargins`를 사용하고 기존 위치 복원·페이지 이미지 재생성 경로를 거친다. 줄 또는 문단 간격을 명시하면 Readium의 `publisherStyles`를 끄므로 EPUB 출판사 문단 스타일 일부가 달라질 수 있다. 두 설정을 모두 기본으로 돌리면 출판사 스타일을 다시 사용한다. 페이지 여백은 좌우와 두 페이지 중앙 간격을 함께 조절하며 중앙만 따로 설정하지 않는다. TXT의 원문 빈 줄은 삭제하지 않는다.

## 묶음 진행 상태

- 서재 카드: `완독 1/3권`처럼 묶음 전체 완독 수를 표시한다.
- 묶음 상세: 전체 권수, 완독 수, 현재 읽는 권의 순번, 완독 비율을 표시한다. 비율은 읽은 글자 수가 아니라 사용자가 완독 표시한 권수 기준이다.
- 이어읽기는 가장 최근에 읽은 미완독 구성원으로 연결한다. 읽던 책이 없으면 저장된 묶음 순서의 첫 미독 책에 읽기 시작을 제공한다.
- 모두 완독한 묶음은 완료 상태를 안내하며 임의로 이어읽기 대상을 정하지 않는다. 각 책은 여전히 직접 열 수 있다.
- 기록을 불러오는 중이거나 오류가 있으면 임의의 0권/미독 상태를 확정해 표시하지 않는다.

## 마지막 페이지 안내

공통 본문 위치 스크립트에서 현재 문서의 스크롤 크기·뷰포트·실제 스크롤 위치로 문서 끝을 판단한다. 호스트에서 마지막 reading-order 항목인지 추가 확인한다. 페이지 시작 위치의 진행률이 100% 미만이어도 마지막 페이지를 안내할 수 있다. 한 페이지·두 페이지·연속 스크롤에 같은 기준을 쓴다.

마지막 화면의 하단 메뉴에 마지막 페이지와 다음 권 제목을 표시한다. 기존 메뉴 영역을 사용해 본문 높이를 바꾸지 않는다. 긴 제목은 줄임표로 표시되고 다음 권 확인창에서 전체 제목을 확인한다. Android는 기존 다음 권 버튼을, iOS는 하단 다음 버튼을 `이어서 읽기`로 표시한다. 사용자가 확인하면 기존 닫기 체크포인트를 저장하고 다음 권을 연다. 자동 이동·자동 완독 처리는 하지 않는다. 다음 권이 없으면 마지막 페이지 안내만 표시한다.

## 실기기 점검 순서

1. TXT/EPUB을 열고 줄·문단 간격과 여백을 바꾼다. 현재 문장 유지, 다음 페이지 이동, 책장 애니메이션을 확인한다.
2. 다른 책을 열거나 앱을 재실행해 설정이 유지되는지 확인한다. 기본 선택으로 원래 문단 배치를 복원한다.
3. 접힘/펼침·회전·연속 스크롤 전환 후 위치와 여백을 확인한다.
4. 묶음 일부만 완독 표시하고 가장 최근 미완독 책으로 이어읽기가 연결되는지 확인한다.
5. 책 중간 장의 끝에는 마지막 페이지 안내가 나오지 않고 실제 마지막 장의 마지막 화면에만 나오는지 확인한다. 이전 페이지로 돌아가면 안내가 사라져야 한다.
6. 다음 권 열기를 취소한 뒤 현재 책에 남는지, 확인하면 저장 후 다음 권으로 이동하는지 확인한다. 마지막 권은 안내만 표시한다.
