# 내 서재의 책 묶음

## 사용 방법

- 서재 상단의 묶음 만들기 버튼 또는 책 `⋯ → 책 묶음 만들기`에서 이름을 입력하고 두 권 이상 선택한다.
- 책을 길게 눌러 다른 책 위에 놓아도 같은 생성 화면이 열린다. 확인 전에는 묶음이 저장되지 않는다.
- `⋯ → 묶음에 추가` 또는 책을 기존 묶음 위에 놓아 추가할 수 있다. 다른 묶음에 소속된 책은 먼저 꺼낸다. 묶음 안에 묶음을 넣지는 않는다.
- 묶음 표지를 누르면 순서대로 책이 표시된다. 마지막으로 읽던 미완독 책을 이어 읽거나 개별 책을 선택한다. 오른쪽 순서 손잡이를 끌면 읽을 순서를 변경할 수 있다.
- 묶음 관리에서 이름과 표지를 변경하거나 책을 추가한다. 표지는 개인 책 표지와 같은 저장 방식을 사용한다.
- 내부 책의 `⋯ → 묶음에서 꺼내기`는 해당 책만 서재로 돌려보낸다.
- `묶음 관리 → 묶음 해제`는 모든 책을 서재로 돌려보낸다. 파일을 삭제하지 않는다.
- 생성·추가·이름 변경·꺼내기·전체 해제 후 안내의 `실행 취소`로 직전 변경을 되돌린다. 이후 묶음 구성을 변경했다면 이전 실행 취소는 적용하지 않는다.
- 한 권 또는 0권이 남아도 묶음은 유지한다. 책 추가와 묶음 해제를 계속 사용할 수 있다.

## 저장 및 읽기 기록

- `library_book_groups_v1`에 묶음 ID, 이름, 원래 책 ID의 순서 목록과 변경 버전을 저장한다.
- 책의 실제 TXT/EPUB 파일, 개별 표지, 책 ID, 네이티브 읽던 위치와 북마크는 합치거나 변환하지 않는다.
- 서재에서 소속 책은 묶음 표지 하나로 표시되며, 검색은 묶음 이름과 내부 책 제목·작가를 포함한다.
- 모든 구성원이 완독이면 묶음도 완독으로 분류한다. 읽은 책이나 일부 완독한 책이 있으면 읽는 중으로 분류한다.
- 삭제되었거나 숨겨진 책은 묶음 화면에서 제외한다. 묶음 표지용 임시 Book 객체는 읽기 엔진으로 전달하지 않는다.
- 개인 기기의 로컬 기능이며 Firebase나 관리자 데이터는 수정하지 않는다.

## 검증

- 저장/재시작, 순서 보존, 중복 소속 거부, 직렬 저장, 저장 실패 및 손상된 메타데이터 보존.
- 꺼내기/해제 실행 취소 및 이후 변경을 덮어쓰지 않는 버전 검사.
- 화면 생성/추가/끌어놓기 취소/권 순서 변경, 내부 제목 검색, 읽기 상태 필터, 원래 책 ID로 이어 읽기.
- 휴대폰과 넓은 화면에서 큰 글자 설정을 사용한 레이아웃 검사.
- 실제 Android/iOS 기기에서는 긴 누르기 후 끌기, 이미지 선택, 앱 재실행 후 묶음과 읽던 위치 유지 여부를 확인한다.
