# 월간 쿠피 운영 및 구현

2026-10-25. 코드 구현 단계. 운영 서버 배포·앱 스토어 빌드/제출은 별도.

## 사용자 흐름

- 서재의 오늘의 쿠피: 언어별 최신 공개 월간호의 최신 발행 회차를 표시한다. 읽기를 누르면 미설치 회차를 받아 동일한 catalog book ID로 연다.
- 지난 이야기: 해당 월간호 회차 목록. 회차별 표지·발행 당일 새 이야기·읽기 진행 상태·직접 읽기.
- 받은 회차는 `group_monthly_{seriesId}` 서재 묶음에 모인다. 책 파일·네이티브 locator·책갈피 ID는 바꾸지 않는다. 사용자가 다른 묶음에 옮긴 책은 다시 가져오지 않는다.
- 합본 공개와 월간호 연결이 모두 완료되면 서버의 다운로드 목록에서 연재 대신 합본을 제공한다. 새 월간호가 등록되면 오늘의 글은 그 월간호에서 가져온다.
- 합본 안내는 연결 공개 시점부터 30일간 제공한다. 확인했어요는 해당 합본 ID의 안내만 이 기기에서 숨긴다. 합본 자체는 다운로드 목록에 계속 남는다.
- 기존 회차·기록은 자동 삭제하지 않는다. 합본은 별도 책이므로 회차의 책갈피/읽던 위치를 합본으로 자동 이식하지 않는다.
- 합본이 비공개/삭제되거나 조건을 충족하지 않으면 기존 연재의 목록 노출을 복구한다.

## 관리자 작업 순서 (Quiz_Site)

1. 월간 쿠피 → 월간호 · 회차에서 언어·제목·대표 표지·발행 월(예: 2026-11)을 지정해 공개한다. 언어별로 작품을 각각 만든다.
2. 회차별 EPUB 또는 TXT, 이미지, 제목, 공개 일시(한국 시간)를 입력하고 예약 저장한다. 예약 시각 전에는 목록과 다운로드가 모두 차단된다.
3. 일괄 등록에서 파일을 넣고 시작 일시와 발행 간격(기본 하루)을 지정한 후 일정 적용을 누른다. 회차 번호순으로 배정되며 날짜는 회차 번호와 별개다. 각 행의 일시를 수정할 수 있다. 발행 월을 넘어간 행은 오류로 표시한다. 예약·공개 버튼으로 확정하고, 과거 일시는 즉시 공개한다. 이미 저장된 행은 개별 편집 화면에서 수정한다.
4. 월간호에서 **월말 자동 합본 생성**을 켜고 공개일 기준을 확인한 뒤 수정하고 공개한다. 다음 달 1일 한국 시간 0시 이후 매시간 확인하여, 해당 월에 공개된 회차가 있으면 합본을 자동 생성한다.
5. 조기에 마감하려면 **지금 합본 만들고 마감**을 누른다. 초안·비공개·미래 예약·다른 달 회차는 제외한다. 직접 만든 EPUB 합본 연결도 기존처럼 가능하다.
6. 다음 월간호도 1번부터 등록한다. 빈 다음 월간호는 자동 생성하지 않는다.

발행 날짜는 한국 시간(Asia/Seoul) 기준. 앱 기기 시간을 변경해도 서버의 미래 회차 다운로드 제한은 유지된다. 한국어/영어/일본어는 기존 언어 필터를 사용하며, 지원하지 않는 기기 언어는 영어로 해석한다. 번역본이 없다고 다른 언어 회차를 대신 노출하지 않는다.

공개한 월간호의 발행 월·언어는 변경할 수 없다. 잘못 등록했다면 새 콘텐츠를 만들고 기존 콘텐츠의 공개 여부를 정리한다. 일반 연재를 월간호로 소급 전환하는 UI는 제공하지 않는다.

## 데이터와 API

- 기존 `readerContent` / 공개 스냅샷 사용. 새 컬렉션이나 로그인 없음.
- `issueMonth`: `YYYY-MM`, 빈 값이면 일반 콘텐츠.
- `releaseAt`: `YYYY-MM-DDTHH:mm:00+09:00`, 한국 시간 공개 시각. 서버가 현재 시각과 비교한다.
- `releaseDate`: 공개 일시로부터 산출한 `YYYY-MM-DD`. 예전 날짜만 있는 회차는 해당 날짜 한국 시간 자정 공개를 유지한다.
- `compilationId`: 연재에만 설정. 같은 월·언어의 공개된 단권 EPUB + 완결 상태 검증.
- 공개 스냅샷의 `compilationLinkedAt`: 안내 시작 시점. 동일 합본의 단순 재공개로 초기화하지 않음.
- `readerCatalog?action=monthly&language=ko|en|ja`: 현재 회차/부모 월간호 및 최근 연결 합본 반환.
- 기존 목록·회차 수·서명 다운로드 URL 발급에도 미래 발행일 제한 적용.
- 부모 연재를 비공개로 만들지 않고 유효 합본이 있을 때만 목록에서 숨김. ID로 조회하는 기존 회차 접근은 유지.
- 앱은 시작·복귀 및 포그라운드 5분 간격으로 월간 목록을 새로 확인. 네트워크 실패가 기존 오프라인 서재를 막지 않음.
- 다운로드 파일 검증 성공 후 묶음 저장 실패는 파일을 롤백하지 않음. 이 경우 받은 책은 일반 서재에 남으며 수동 묶음 정리 가능.

## EPUB 이미지 제작 규칙

현재 뷰어는 별도 표지를 본문 첫 칸에 넣는 준비 코드를 이미 가지고 있다. 본문에 출판사 표지 페이지가 있으면 중복 삽입을 피하므로, **회차 EPUB에 별도 표지 페이지를 넣지 않고 관리자 회차 표지를 지정**하는 구성이 가장 단순하다. 한 페이지 배치에서는 표지 다음 글, 두 페이지 배치에서는 첫 칸 표지 다음 칸 글로 흐른다. 연속 스크롤 모드는 페이지 고정 배치를 보장하지 않는다.

합본은 각 이야기를 별도 XHTML spine 항목으로 만들고, **동일 XHTML 안에서 이미지 다음 본문** 순서로 제작한다. 이미지와 본문을 서로 다른 spine 항목으로 나누면 두 페이지에서 맞은편 배치를 보장할 수 없다. 다음은 제작 시 참고할 CSS이며 실제 EPUB을 넣어 iOS/Android에서 최종 확인해야 한다.

```css
.story-image {
  width: 100%;
  height: calc(100vh - 2px);
  margin: 0;
  break-inside: avoid;
  -webkit-column-break-inside: avoid;
  break-after: column;
  -webkit-column-break-after: always;
}
.story-image img { width: 100%; height: 100%; object-fit: contain; }
```

합본은 현재 파일당 20MiB 제한을 지킨다. 28~31장의 이미지는 압축해 넣는다. 텍스트 1~2쪽은 제작 분량 기준이며 사용자의 글꼴·글자 크기에 따른 실제 페이지 수는 달라진다.

## 회차 EPUB · 월말 합본 자동 생성 (2026-10-25)

- 같은 파일명의 TXT와 PNG/JPG/WebP를 올려 회차를 공개한다. TXT는 문단 사이 빈 줄만 있으면 되며 `[장]`은 필요 없다. 첫 줄이 회차 제목과 같으면 중복 제목을 제거한다.
- TXT는 원본으로 보관하고 공개 스냅샷에는 생성한 EPUB을 제공한다. 선택 입력한 글쓴이는 이미지 위에 표시한다. 첫 이미지 뒤 본문을 배치하며 이미지 종횡비를 유지한다.
- 한국어·영어·일본어 EPUB 언어와 글쓴이 라벨, 회차별 목차를 생성한다. 월간호 언어마다 별도 합본이다.
- 과거 직접 올린 EPUB은 그대로 이용 가능하다. 자동 합본에 넣으려면 회차 TXT를 등록하고 다시 공개해야 한다. 과거 TXT 공개본은 원본 TXT와 표지로 합본 생성 가능하다.
- 기존 월간호는 자동 합본 기본 꺼짐. 관리자에서 자동 생성을 켜서 **공개**해야 적용된다.
- 대상 공개 회차의 TXT 원본 누락이면 마감하지 않는다. 초안·비공개·다른 달 회차는 대상을 선정할 때 제외한다. 관리자 오류에 이유를 남기고 다음 시간에 재시도한다.
- 합본은 공개 스냅샷만 사용한다. 아직 공개하지 않은 수정 내용은 넣지 않는다. 한국 시간 공개 일시 순서대로 이미지·본문을 넣는다. 같은 시각이면 회차 번호와 ID 순으로 정렬한다. 첫 회차 이미지가 내부 첫 장이며 다운로드 목록 표지는 월간호 대표 표지를 사용한다.
- 합본 파일 저장 후 Firestore 트랜잭션에서 합본 공개와 월간호 연결을 동시에 적용한다. 작업 도중 월간호·회차 수정/추가/삭제가 있으면 전환하지 않는다. 동시 생성은 한 건만 성공하고 나머지 임시 EPUB은 정리한다.
- 원본·기존 공개 회차·사용자 다운로드·책갈피는 삭제하지 않는다. 이미 받은 TXT가 자동으로 EPUB으로 교체되지는 않는다.
- 월간 TXT 본문은 UTF-8 기준 1MiB, 생성 준비 원본 합계 32MiB, 최종 EPUB 20MiB 한도. 초과 시 기존 회차를 유지하고 오류 표시.
- ZIP 생성 라이브러리: fflate 0.8.3 (MIT), package-lock 고정. 클라이언트 추가 라이브러리 없음.

## 공개일 기준 합본 (최신 기준)

예정 회차 수 입력과 검증을 제거했다. 기존 expectedEpisodes 값은 호환성을 위해 읽을 수 있지만 생성 조건에 사용하지 않는다.
해당 월간호·같은 언어의 공개 스냅샷에서 releaseAt을 사용하고, 예전 날짜만 있는 회차는 releaseDate의 한국 시간 자정으로 처리한다. 업로드 시각이나 초안의 변경 날짜를 사용하지 않는다.
10월호 범위는 10월 1일 00:00 KST 이상, 11월 1일 00:00 KST 미만이다. 비공개·삭제 중·초안·미래 예약은 제외한다. 공개 회차가 없으면 빈 합본을 만들지 않는다. 수동 마감은 현재까지 공개된 대상만 포함한다.
서버 단위 테스트 36개에 월 경계·UTC/KST 변환·정렬·초안 날짜 무시·기존 예정 수 무시 검증 포함.

### 월간 쿠피 발행자와 이용조건
- 월간 콘텐츠 발행자는 `쿠피랩`으로 자동 저장하며 공개 API에서는 발행자를 숨깁니다. 회차 글쓴이(byline)는 선택이며 입력한 경우에만 표시됩니다.
- 이용조건은 개인 독서 허용·무단 복제/재배포/상업 이용 금지 문구를 기본 적용하며 관리자가 수정할 수 있습니다. 회차는 월간호 조건을 상속하고 자동 합본도 이를 사용합니다.
- 기존 공개 데이터도 API 응답에서 발행자를 숨깁니다. 이미 기기에 다운로드한 책의 메타데이터는 자동 변경하지 않습니다.
- 앱의 빈 저자 구분점 정리는 다음 앱 빌드에 포함합니다. 서버 및 관리자 변경은 별도 배포합니다.

### 서재 월간 카드 접기
월간호 제목 옆 화살표로 접기/펼치기. `monthly_section_expanded_v1` 로컬 설정으로 다음 실행에도 복원하며 첫 사용은 펼침. 접으면 회차 본문·이미지·버튼은 숨기고 제목 및 미열람 최신 회차 NEW 배지를 유지. 회차 cover도 미리보기 다운로드 대상으로 허용. 월간 회차 카드가 있으면 큰 환영 문구를 생략하되 이어 읽기는 유지.

### 월간 묶음 표지 복구
