# 앱 아이콘과 시작 화면

- 원본: `assets/branding/app_icon.png`, `assets/branding/book.svg`.
- 배경: `#F7F5EE`. 시스템 다크 모드에서도 동일하며 별도 문구는 표시하지 않는다.
- Android/iOS의 정적 실행 화면에 너비 144 논리 픽셀의 책을 배치한다.
- Flutter에서 같은 도형으로 800ms 동안 오른쪽 책장을 왼쪽으로 한 번 넘긴다.
- 서재는 애니메이션 중부터 로드되며 종료 후 기존 하단 영역과 함께 표시된다.
- 앱 복귀나 라우트 변경 시 재생하지 않는다. 새로운 앱 시작에는 재생한다.
- 시스템 동작 줄이기 설정에서는 애니메이션을 생략한다.
- 기존 리더, 독서 위치 저장, 광고 기능과 서재 색상은 변경하지 않는다.

## 재생성

Python 3와 Pillow가 설치된 환경에서 `python3 tool/generate_branding.py`를 실행한다.
PNG의 플랫폼별 아이콘, iOS 정적 이미지, Android 벡터, Flutter 경로를 생성한다.
런타임 SVG 파서나 애니메이션 패키지는 필요하지 않다.
SVG는 오른쪽 책장, 왼쪽 책장, 오른쪽 표지, 왼쪽 표지 순서의 네 path를 사용한다.
생성기는 현재 원본에 사용된 M/L/C/Z 명령을 지원한다.

Android 12 이상에서는 OS가 자체 스플래시 전환과 마스킹을 관리한다.
책장 넘김은 그 뒤 Flutter에서 실행한다. iOS LaunchScreen은 정적 화면이다.

## 검증

Flutter 테스트 79개, 정적 분석, Android debug APK 및 iOS simulator 빌드 통과.
실기기에서는 기존 설치 위에 업데이트하고 앱을 완전히 종료한 뒤 다시 실행해 전환을 확인한다.
홈으로 나갔다 돌아올 때는 반복 재생되지 않아야 한다.
독서 기록을 유지하기 위해 앱 삭제 없이 업데이트한다.
