# 독서 편의성 피드백 패치 — 2026-10-16

## 변경 동작

- Android/iOS 줄간격: 책 기본값 또는 1.00~3.00배, 0.05배 단위. 슬라이더는 놓을 때 적용하고 작은 단계 조절 버튼을 함께 제공한다. 기존 anchor 복원 경로를 유지한다.
- 독서 설정의 완료를 `닫기 ×`로 바꾸고 상단/탭/행 여백을 확보했다. Android 헤더/탭은 스크롤 밖에 고정하고 양쪽 플랫폼의 줄간격을 글자 크기 바로 아래로 옮겼다. 적용은 기존처럼 즉시 반영한다.
- 하단 표시: 없음 / 진행률 / 위치 / 함께. Android/iOS 표시 기준을 통일한다. 이전·다음에 방향 표시를 넣고, 별도 읽던 위치 복귀 버튼은 복귀 기록이 있을 때만 표시한다.
- 목차 및 책갈피에 내용 기준 위치/전체 위치와 진행률을 표시한다. Readium positions 목록에서 앱이 삽입한 표지를 제외하며, 위치가 없는 예전 책갈피는 같은 자원의 progression으로 표시 위치를 추정한다. 전체 진행률이 없으면 해당 content position의 값을 이용하고, 그것도 없으면 위치 단위 비율을 쓴다.
- 이것은 현재 화면 페이지나 인쇄본 쪽수가 아니다. Readium 위치 단위는 플랫폼/엔진에 따라 달라질 수 있다. 목차의 fragment를 정밀하게 계산하지 못하면 해당 자원의 시작 위치를 `약 위치`로 표시한다. 정확한 position이 없는 예전 기록의 보간 위치도 `약 위치`, 전체 진행률 없이 위치 단위로 산출한 비율은 `약`으로 구분한다. 숫자는 표시용이며, 이동/복원은 원래의 Locator를 사용한다. 확인할 위치가 없으면 숫자를 만들어 표시하지 않는다.
- 네이티브 텍스트 선택 메뉴에 `선택 문장에 책갈피` 추가. 선택된 Locator와 문맥을 그대로 저장하고 선택 문장을 기본 이름으로 제안한다. 기존 현재 위치 저장도 유지한다.
- 자동 페이지 넘김: 5~300초, 기본 30초. 설정에서 수동 시작하고 하단 일시정지 버튼을 제공한다. 연속 스크롤 모드는 제외한다. 선택/설정/목차/도구/번역/광고 상호작용/책 끝/백그라운드/오류에서 정지한다. TTS와 동시에 진행하지 않는다. 레이아웃/넘김 작업 중에는 다음 전체 간격을 기다린다. 일반 이동이 완료되면 간격을 다시 센다. 활성 중에는 화면 꺼짐을 막고 종료 시 해제한다.
- 저장되는 값은 간격뿐이다. 자동 넘김 활성 상태는 저장하지 않으며, 새 독서 세션/앱 복귀 시 자동 재개하지 않는다.
- 서재의 최근 읽은 책은 완독 표시 때문에 사라지지 않는다. 완독 상태도 카드에 표시한다.
- 기본 글꼴에 나눔고딕 Regular / 나눔명조 Regular 추가. 원본 TTF는 수정하지 않았으며 합계 약 4.88 MiB 증가한다. 선택 목록에는 같은 예문을 실제 글꼴로 표시한다. 한국어/영어/일본어 문구와 내장 설명서도 갱신한다.

## 후속 보완 — 자동 넘김 재개·추정 위치·다음 회차

- 자동 넘김을 한 번 사용한 독서 세션에서는 정지해도 하단 버튼을 유지한다. 재생/일시정지 아이콘과 지정 간격을 함께 표시하고 접근성 레이블에는 동작과 간격을 읽어 준다. 간격 변경은 즉시 반영한다. 다음 세션에는 처음처럼 숨기며 백그라운드 복귀 시 자동 재생하지 않는다.
- 연속 스크롤·책 끝·TTS 진행/준비·번역 중에는 재개 버튼을 비활성화한다. TTS가 재생/준비 중이면 자동 넘김 버튼 대신 듣기 조작부를 보여 주고, 일시정지하면 자동 넘김 재개 버튼으로 돌아온다. 두 조작부를 한 줄에 동시에 배치해 좁은 화면이 넘치지 않게 한다. iOS 툴바 중앙 항목도 현재 듣기 상태를 따른다.
- 목차의 fragment가 있는 항목은 정밀 DOM 위치 계산 전이므로 추정으로 표시한다. position 번호가 다른 자원을 가리키는 오래된 Locator는 해당 번호를 정확한 위치로 간주하지 않는다. 원본 Locator/읽던 위치/책갈피에는 표시용 숫자를 쓰지 않는다.
- 최근 책이 완독 상태이고 같은 묶음의 바로 다음 파일이 로컬 서재에 있을 때 `다음 회차 읽기`를 제공한다. 사용자가 저장한 묶음 순서를 그대로 따르며, 다음 파일 누락/마지막 회차/단권/미완독이면 숨긴다. 완독한 책의 `이어 읽기`도 보조 버튼으로 유지한다. 서버에서 임의 회차를 받거나 자동 이동하지 않는다.
- UI 문구와 내장 설명서는 한국어/영어/일본어 모두 갱신한다.

후속 검증: Flutter 전체 302개와 정적 분석 통과. Android API36 에뮬레이터 및 SM-G988N(Android13)에서 각각 11개 네이티브 테스트 통과(동일 검사 2기기). 실제 자동 넘김→정지→버튼 유지→재개, 백그라운드 복귀 후 정지 유지, 기존 위치/글꼴/줄간격 회귀를 확인했다. 한국어/영어/일본어 서재의 320px/840px 다음 회차 CTA와 원래 Book 객체 라우팅을 검증했다. iOS 기기용 Debug 빌드도 성공했으며 실기기 동작 확인은 남아 있다.

## 위치 번호 제거와 책갈피 관리 — 2026-10-16

- 사용자 화면에서는 Readium 위치/전체 위치 번호를 제거한다. 하단 선택은 없음/진행률 두 개만 제공한다. 기존 footerInfo=location/both는 파싱·백업 호환을 유지하되 화면에서는 진행률로 취급한다. 목차/책갈피의 detail도 진행률만 표시한다. 원본 Locator와 positions 기반 내부 복원·진행 추정은 유지한다.
- 상단 검색과 책갈피를 분리한다. 검색 아이콘은 검색을 바로 열고, 책갈피 아이콘은 관리 목록을 바로 연다. 설정도 아이콘+접근성 이름으로 표시해 작은 화면/번역 문구가 겹치지 않게 한다.
- 책갈피 관리: 이곳에 추가/해제, 최신 저장 순 목록, 항목마다 이동/이름 변경/삭제, 삭제 직후 실행 취소. 처음 추가할 때 이름 팝업을 강제하지 않고 문장/장 이름을 자동 사용한다. 선택 문장 저장은 선택 Locator와 문장을 그대로 저장한 뒤 관리 목록에서 확인할 수 있다. 기존 100개/512KiB 제한을 유지한다.
- 현재 책갈피 인식은 반올림한 진행률이 아니라 href 및 정확한 koofyText 앵커 또는 정규화한 Locator로 비교한다. 같은 숫자의 0/0.0 표현 차이는 동일하게 처리한다. 가까운 다른 문자나 다른 자원은 합치지 않는다.
- Android Readium의 Locator.fromJSON은 일부 JSON 필드를 소비하므로, 목록 행의 원본 JSON을 직접 넘기지 않고 복사본을 해석한다. 목록 재표시/삭제 취소/이동에서 기존 fragments가 사라지지 않도록 한다. 저장 형식과 기존 항목 ID는 유지한다.
- 저장 실패 시 목록은 기존 항목을 유지한다. iOS 오류는 관리 창 안에 표시해 이름 변경 팝업과 오류 팝업이 겹치지 않게 한다. 한국어/영어/일본어와 설명서를 함께 갱신한다.

검증: Flutter 전체 302개 및 정적 분석 통과. SM-G988N(Android13)에서 저널·책갈피 원본 보존·목록 테마·영어/일본어 UI 17개, 책갈피 추가/삭제 실패/삭제/실행 취소/바로 이동·설정 패널·자동 넘김 3개가 통과했다. 실제 관리 목록 스크린샷도 확인했다. iOS 기기용 Debug 및 build-for-testing 컴파일 성공(실기기 실행은 하지 않음). Android Debug APK를 빌드했으며 버전과 스토어 배포 설정은 변경하지 않았다.

최종 Debug APK를 SM-G988N에 기존 데이터를 유지하는 업데이트 방식으로 설치했다(adb install -r: Success).

## 앱 테마와 독서 배경 — 2026-10-16

앱 설정에 앱 테마(기기 설정 따르기/밝게/어둡게)를 추가하고 SharedPreferences의 app_theme_v1에 저장한다. MaterialApp과 서재·묶음 책장·묶음 편집이 같은 앱 테마를 따른다. 독서 설정의 배경은 ‘독서 배경’으로 명확히 구분하며 앱 테마 따르기/종이색/밝게/어둡게를 제공한다. 새 독서 기본값은 app이며 기존 light/sepia/dark는 강제 변경하지 않는다. 저장·백업·체크포인트는 app 토큰을 보존하고 실제 Readium/목차/책갈피/설정/도구 색상은 렌더링할 때만 해석한다. Android와 iOS는 동일한 앱 테마 설정을 읽고 시스템 테마 변경도 반영한다. iOS는 시스템 따르기에서 인터페이스 스타일을 강제하지 않는다. 한국어/영어/일본어 문구와 내장 설명서도 갱신했다.

검증: Flutter 전체 303개 및 테마 설정 UI 추가 검사 통과. Android SM-G988N에서 앱 테마 밝게/어둡게/시스템 연결, 명시한 종이색 유지, 원본 읽기 앵커 보존 및 설정 패널 회귀 2개 통과. iOS 기기용 Debug 빌드 성공(실기기 실행은 하지 않음). 스토어/앱 버전은 변경하지 않았다.

최종 정적 분석 통과. 새 APK는 SM-G988N에 기존 데이터를 유지하며 업데이트 설치했다(adb install -r: Success).

## 전체 설정 패널과 단일 테마 — 2026-10-16 (앞선 독서 배경 분리 정책 대체)

- 전체 설정은 기존 /settings 경로에서 오른쪽 슬라이드 오버레이로 열린다. 휴대폰은 약 2/3, 넓은 창은 한쪽 영역의 약 2/3 폭이며 최소 240을 확보한다. 접힌 기기에서는 DisplayFeatureSubScreen으로 우측 화면 안에 배치한다. 바깥 탭/닫기/뒤로가기로 서재에 돌아가며 스크롤 등 기존 서재 상태를 유지한다.
- 앱 테마는 패널 안에서 펼쳐 기기 설정 따르기/밝게/종이색/어둡게를 고른다. 종이색도 앱 전체에 적용한다. 백업/휴지통/개인정보 등 기존 기능과 보상 광고 흐름은 유지한다.
- 뷰어 설정에서 독서 배경 항목을 제거했다(Android/iOS 8개 항목). 새 세션은 예전 저장/백업의 독서 배경값과 관계없이 theme=app으로 시작한다. 과거 데이터 파싱은 유지하되 실제 앱에서는 전체 설정만 테마를 결정한다. 읽던 위치와 책갈피는 변경하지 않는다.
- 뷰어 상단 ‘서재’는 나가기 아이콘으로 변경하고 ‘서재로 돌아가기’ 접근성 이름 및 Android 길게 누르기 안내를 제공한다. 한국어/영어/일본어 문구와 설명서 갱신.

검증: Flutter 전체 306개, 정적 분석 통과. 390/840폭 패널 정렬·폭·펼침·바깥 탭 닫기, 종이색 저장과 이전 테마를 무시한 다음 책 열기 회귀 포함. ## 서재 검색 펼침과 작업 버튼 축소 — 2026-10-16

기본 작업 행은 돋보기 아이콘 / 도서·글꼴 다운로드 / 책 추가로 폭을 채운다. 돋보기를 누르면 240ms 동안 검색 폭이 늘어나고 다운로드·책 추가는 48px 아이콘 버튼으로 줄어든다. 책 추가는 책+ 모양을 사용한다. 검색 닫기는 키보드와 검색어를 정리하고 레이블 버튼을 복원한다. 검색 컨트롤러·정렬·필터·다운로드 탭 동작은 유지한다. 기존 목록 위 상시 검색창은 제거했다. 세 언어 안내/툴팁 제공.

검증: 서재 회귀 46개와 정적 분석 통과. KO/EN/JA 320폭에서 애니메이션 중간 프레임과 종료 후 잘림 없음, 검색 열기/작가 필터/닫기 후 결과 복구 및 라벨 복원 포함. Android Debug APK 빌드 후 SM-G988N에 기존 데이터 유지 업데이트 설치. 스토어 배포 없음.

언어 버튼: 지구본 우측 하단에 현재 적용된 KO/EN/JA 코드 배지를 추가했다. 기기 언어 따르기도 실제 적용 언어를 표시하며 기존 메뉴 동작을 유지한다. 밝게/종이색/어둡게 색상은 현재 앱 테마를 따른다. 언어/서재 검사 51개 및 정적 분석 통과, Android Debug 빌드 후 실기기에 업데이트 설치했다.
