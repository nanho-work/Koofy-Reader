# 쿠피리더 1.9.0 (19) 빌드와 스토어 문구

작성: 2026-10-30. 이번 요청 범위는 Android·iOS 배포용 파일 생성이다. 스토어 업로드·심사 제출·게시, Remote Config, Git 커밋·푸시는 하지 않는다.

## 변경 내용

- 홈·도서·서재·설정으로 화면을 분리하고 홈에 한 장씩 넘기는 추천 배너와 사연 보내기를 배치했다.
- 넓은 화면에서 사이드 메뉴와 책 그리드를 사용한다. 독서 화면은 사용 가능한 폭 600dp/pt 이상에서 자동 두 페이지 보기를 사용하며, 사용자가 선택한 한 페이지 설정을 보존한다. 스크롤 읽기·표지·실제 힌지 안전 처리에는 별도 규칙이 있다.
- 독서 화면의 안전 영역, 마지막 화면의 완독 처리, 한국어·영어·일본어 문구를 개선했다.
- 배너는 독서 뷰어에만 표시한다. 보상형 광고 완료 시 광고 제거는 4시간이다.
- 첫 실행의 자체 선택 팝업을 없애고 선택은 설정에서 제공한다. 필수 광고 동의 절차는 유지한다. 신규 사용자의 통계 수집은 기본 꺼짐이다.

## 홍보 방향

첫 문구는 **“폴더블·태블릿에서 책처럼 두 페이지로”**를 사용한다. 휴대폰에서도 TXT·EPUB 독서와 TTS를 사용할 수 있다는 설명을 함께 둔다.

기종 이름을 반복하는 검색어 나열이나 ‘모든 기종 완벽 지원’은 쓰지 않는다. Duo 시뮬레이터와 Fold 에뮬레이터 확인을 실제 판매 기종 전체의 실기기 검증과 구분한다. 큰 화면 두 페이지 본문 스크린샷과 휴대폰 한 페이지 스크린샷을 함께 준비하는 것이 적합하다. 현재 스토어 이미지는 이번 문서 작성으로 교체되지 않는다.

## 검색 유입 확인 방법

### Google Play

공식 문서 경로는 `사용자 늘리기 → 스토어 실적 → 전환 분석`이다. 운영자 화면에는 이 메뉴가 없으므로 실제 보이는 `사용자 늘리기` 하단의 **스토어 등록정보 →** 카드부터 확인한다. 보고서가 열리면 최근 28일 또는 90일, 트래픽 소스와 **검색어** 측정기준을 찾는다. 국가별 한국·일본·미국 등으로 비교한다. 현재 이 계정의 검색어 표는 아직 확인하지 못했다.

2026년 보고서 개편으로 클릭수/CTR과 설치 완료 수가 구분된다. 검색어 표의 유입은 전체 검색 노출 순위와 같지 않다. 적은 트래픽은 ‘기타’로 묶일 수 있다. 공개되지 않은 키워드를 임의로 추정하지 않는다.

출처: [Google Play 실적 도움말](https://support.google.com/googleplay/android-developer/answer/9859173?hl=ko)

### Apple

`App Store Connect → 앱 → 분석 → 유입 경로 → 소스`에서 App Store 검색 및 국가/지역별 최초 다운로드를 비교한다. 일반 분석의 검색 소스는 개별 자연 검색어 목록이 아니다. Apple Ads의 Search Terms는 광고 유입 보고서이므로 자연 검색 유입과 혼동하지 않는다. 유입 확인만을 위해 광고 결제를 시작할 필요는 없다.

출처: [Apple 유입 경로 분석](https://developer.apple.com/help/app-store-connect-analytics/acquisition/acquisition/), [Apple Ads 검색어 보고서](https://ads.apple.com/app-store/help/get-started/0013-understand-dashboards-and-settings)

### 적용 순서

현재 수치·기간·국가·검색어를 기록한 다음 소개 문구와 이미지를 바꾸고 동일 길이의 기간으로 비교한다. 위 홍보 문구는 기능에 근거한 초안이며 현재 검색어 실적에 근거한 최적화 완료본은 아니다.
