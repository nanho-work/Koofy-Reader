# 기본 제공 도서 교체 — 2026-10-06

신규 설치의 기본 책은 `인어공주는 파도를 벤다 1화`와 `쿠피리더 시작하기`다. 소설은 사용자가 제공한 TXT·JPG를 그대로 번들에 넣었으며, 작가명이 제공되지 않아 임의로 기재하지 않았다. 설명서 본문은 유지하고 서재 제목과 녹색 표지를 추가했다.

## 독서 흐름

- 소설 끝에 별도 EPUB spine 페이지 `다음 이야기`를 추가한다. 원본 TXT는 수정하지 않는다.
- `공개된 다음 화 확인하기 →`를 누르면 독서 기록을 저장하고 작품명이 입력된 도서 다운로드 화면으로 이동한다. 뒤로 가면 서재로 돌아온다.
- 다음 화가 이미 등록됐다고 단정하지 않는다. 검색 결과가 없으면 공개 후 내려받을 수 있다는 안내를 표시한다. 새 회차를 공개하는 작업은 별도다.
- Android·iOS는 해당 기본 소설 ID와 정확히 일치하는 앱 내부 링크만 처리한다. 외부 EPUB의 링크 차단 정책은 유지한다.

## 기존 기록과 표지

- 새 소설 ID는 `sample_mermaid_001`이다. `sample_1`의 읽기 위치·북마크·완독·개인 표지를 이어받지 않는다.
- `새벽의 쿠피`의 기존 독서 기록, 준비된 원본, 개인 표지, 완독 상태 또는 묶음 소속이 있으면 기존 책도 유지한다. 사용자가 숨기거나 휴지통으로 보낸 상태는 존중한다.
- 이전 백업에 `새벽의 쿠피`가 포함돼 있으면 복원 후에도 열 수 있다. 새 기본 책과 이전 기본 책 모두 백업 검증 대상이다.
- 설명서는 `sample_2` ID와 EPUB 본문 리비전을 유지하므로 이름·표지 변경으로 읽던 위치가 초기화되지 않는다.
- 개인 표지가 기본 제공 표지보다 우선한다. 표지를 초기화하면 제공된 표지로 돌아간다. 독서 화면의 표지 표시 설정도 그대로 적용된다.

## 검증과 배포 범위

- 기본 도서·개인 표지·본문 리비전·백업·카탈로그 이동 관련 Flutter 테스트 48개, 서재·묶음 화면 회귀 테스트 42개 통과(총 90개).
- `dart analyze lib test packages/koofy_reader_bridge/lib` 통과.
- Android debug APK 및 iOS x86_64 simulator 빌드 통과.
- 실제 서재 위젯을 렌더링해 소설·설명서 표지와 제목을 확인했다. 미리보기: `work/bundled-books/library-preview.png`.
- 전체 테스트 중 광고/설정의 기존 실패 3개는 변경 전 HEAD를 별도 임시 경로에 풀어 동일하게 재현했다: `settings_page_test.dart` 1개, `shared_theme_test.dart` 2개.
- iOS arm64 simulator 실행 확인은 기존 MLKitCommon 프레임워크가 해당 아키텍처의 simulator 바이너리를 제공하지 않아 제한됐다. 기본 x86_64 빌드는 성공했지만 이 Mac의 실행 환경과 맞지 않는다. 실기기에서 마지막 안내 링크를 누르는 확인은 남아 있다.

앱 내장 에셋이므로 사용자에게 적용하려면 다음 앱 업데이트가 필요하다. 이번 작업으로 서버 콘텐츠 게시, 스토어 업로드 또는 심사 제출을 하지는 않았다. 테스트·빌드 로그와 확인용 EPUB은 `work/bundled-books/`에 보관했다.
