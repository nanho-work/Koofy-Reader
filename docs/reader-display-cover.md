# 독서 화면의 등록 표지

## 사용 동작

- 설정 → **독서 화면에 표지 표시**: 기본 켜짐. 다음에 책을 열 때 반영한다.
- 각 권/파일에 직접 등록한 표지만 사용한다. 묶음 대표 표지를 대신 넣지 않는다.
- 처음 여는 책은 표지 → 본문 순서이며, 이어 읽기는 저장된 본문 위치에서 시작한다.
- 표지는 화면 비율에 맞춰 잘리지 않게 표시한다. 펼침 화면에서도 표지는 한 장으로 표시하고 중앙 구분선을 숨긴다. 본문은 기존 한쪽/두쪽 설정을 따른다.
- 연속 스크롤에서는 첫 자원으로 표시한다. 목차의 ‘표지’ 항목으로 다시 이동할 수 있다.
- TTS는 추가 표지를 건너뛰고 본문에서 시작한다. 추가 표지에는 책갈피를 만들지 않는다.
- 표지가 없거나 이미지가 삭제·손상되면 본문부터 정상적으로 열린다.
- EPUB에 원래 표지 장이 있으면 출판물의 표지를 유지한다. 이 경우 등록 이미지로 덮어쓰거나 중복 삽입하지 않는다. 표시 설정을 꺼도 원래 EPUB 표지를 삭제하지 않는다.

## 데이터와 구현

`ReadingPublicationPreparer`에서 검증된 EPUB에 별도 표지 자원을 추가해 독서용 사본을 만든다. 원본 파일은 수정하지 않는다.

- 표지 자원: `__koofy_reader_cover_v1__/cover.xhtml` 및 같은 디렉터리의 `image.png`.
- 본문 XHTML 바이트·href·문단 ID를 보존한다.
- `contentRevision`: 표지 추가 전 원본/변환 EPUB의 SHA-256. 기존 독서 위치와 책갈피의 리비전을 유지한다.
- 독서용 사본 파일명/검증 해시: 표지까지 포함한 실제 사본의 SHA-256. 다른 표지를 같은 파일에 덮어쓰지 않는다.
- 표지를 바꾸거나 꺼도 본문 Locator는 그대로 전달한다. 표지에서 종료한 뒤 표시를 끄거나 이미지를 삭제한 경우에만 없는 표지 Locator 대신 본문 처음으로 연다.
- EPUB3 nav 및 EPUB2 NCX 목차에 표지 항목을 추가한다.
- 이미지는 입력 크기·픽셀 수를 제한하고 최대 변 1,200픽셀의 PNG로 정규화한다. 선택적 이미지 읽기 실패가 책 열기를 막지 않는다.
- 표지와 본문의 열 수가 다르면 넘김 화면을 재생성한다. iOS의 페이지 이미지 준비는 앱이 생성한 단일 표지 자원에 한해 텍스트 없는 위치를 인정한다. 일반 본문의 정확한 문자 위치 검증은 유지한다.
- 전역 표시 설정은 로컬 설정 `reader_show_registered_cover_v1`(0=꺼짐, 1=켜짐, 미설정=켜짐)에 저장한다. 서재 백업의 선택 필드 `displayCover`에 포함하며, 복원 기기에 저장값이 없을 때만 적용한다.
- Readium이 계산하는 전체 진행률에는 표지 자원도 포함되므로 숫자는 달라질 수 있으나, 저장된 본문 문장 위치는 변경하지 않는다.

## 검증

- Flutter: 기존 변환·리더 실행 테스트와 표지 전용 테스트. 본문 바이트/리비전 유지, 표지 변경·삭제·손상, 표시 끄기, 기존 EPUB 표지 중복 방지, EPUB2 목차를 검증한다.
- Android 에뮬레이터: 좁은/넓은 화면의 표지 한 장, 앞뒤 이동, 스크롤 전환, 본문 위치 복원, TTS 시작 위치. 좁은/넓은 화면에서 실제 curl 준비/이동, 본문 열 수 전환 및 즉시 전환 대체가 없음을 확인한다.
- iPad 시뮬레이터: 표지 한 장, 앞뒤 이동, 스크롤 전환, 본문 위치 복원, TTS 시작 위치, 표지 curl과 본문 두 쪽 curl 전환을 확인했다.
- 실제 사용자의 iPhone·Galaxy 폴드 실기기는 이번 검증에 포함하지 않는다. 출시 전 큰 글씨/사용자 글꼴, 접기·펼치기, 실제 표지 비율, 표지와 본문 사이의 손가락 넘김을 확인한다.

## 되돌리기

표지 표시 설정을 끄면 원본/기존 변환 EPUB을 사용한다. 원본·본문 Locator·읽기 기록을 삭제하거나 마이그레이션하지 않는다. 이전 앱 버전으로 돌아갈 경우에는 표지 화면에서 저장한 전용 href를 이해하지 못할 수 있으므로 본문으로 이동한 뒤 종료하거나 표시를 끄고 책을 열어 본문 위치를 저장한다.
