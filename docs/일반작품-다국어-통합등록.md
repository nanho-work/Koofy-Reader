# 일반 작품 다국어 통합 등록

## 구성
- Quiz_Site 관리자 책 관리가 일반 작품·번역본 관리 화면으로 열린다.
- 단권과 연재를 구분하고 한국어·영어·일본어 제목, 저자, 소개, 이용조건, 표지와 본문을 한 화면에서 입력한다.
- 공통 표지보다 언어별 표지가 우선한다. 한국어 저자·분류·출처 복사와 자체 작품 이용조건 적용은 명시적으로 누른 경우에만 수행한다.
- 언어 체크와 제목 입력이 모두 된 항목만 저장/공개한다. 언어별 결과를 표시하며 실패한 언어만 선택해 재시도할 수 있다.
- 연재는 언어 탭별 회차 등록·일괄등록을 제공한다. 파일 한 쌍도 등록 가능하다. 기존 회차 수정은 기존 개별 관리에서 한다.
- 기존 개별 관리와 월간 쿠피 기능을 유지한다.

## 데이터 보존
관리자 전용 translationGroupId만 추가한다. 연결 시 ID, 파일, 공개 스냅샷, 회차 연결을 변경하지 않는다. 앱은 기존 언어별 카탈로그를 계속 사용한다.
연결 트랜잭션은 revision, 중복 언어, 기존 묶음 충돌, 단권/연재 혼합, 월간호/회차/삭제 중 자료를 검사한다.
자동 번역이나 제목 추측으로 기존 자료를 합치지 않는다. 기존 번역본은 관리자가 선택하여 연결한다.

## 공통 삽화 등록
회차 등록·일괄등록 위의 공통 삽화 영역에 `01.png`, `02.png`처럼 회차 번호로 시작하는 이미지를 넣는다. 각 언어 탭에 `01_제목.txt` 등의 본문을 넣으면 제목이 달라도 번호로 연결된다. 각 행에 연결된 공통 이미지 파일명이 표시된다. 동일 번호의 공통 이미지가 여러 장이면 선택 전체를 거절하여 임의로 연결하지 않는다.
언어별 이미지가 있으면 공통 이미지보다 우선한다. 기존에 등록된 회차는 일괄등록으로 덮어쓰지 않는다. 저장은 각 언어 탭에서 수행한다.
첫 저장 때 공통 이미지를 업로드하고 같은 파일 객체는 다른 언어 저장 시 재업로드하지 않는다. 서버는 검증한 이미지 해시로 중복 저장을 방지한다. 공통 이미지 레지스트리는 관리자 인증 뒤에만 접근한다.
공통 이미지는 readerSharedCovers 경로에 보관하여 특정 회차 삭제로 다른 언어의 이미지가 지워지는 것을 방지한다. 현재 미참조 공통 이미지는 자동 삭제하지 않는다(재사용 및 공개 스냅샷 보호). 앱 다운로드는 기존의 공개 파일 서명 URL 방식이며 다른 언어 본문은 내려받지 않는다.
서버 Functions 배포 후 웹 배포 필요. 실서비스 저장·삭제 교차 언어 검증은 배포 후 진행한다.

## 일반도서 등록 화면 개편 (2026-10-31)
- 일반도서는 목록 → 도서 등록 → 파일 연결 미리보기 → 도서 정보 확인 순서로 이동한다.
- 처음부터 단권/회차 셀렉트를 표시하지 않는다. 여러 원고가 있으면 한 작품의 회차 또는 독립 도서를 선택한다.
- 독립 도서는 여러 파일을 준비하더라도 책별로 확인·저장한다. 일괄 공개 버튼은 제공하지 않는다.
- 세 언어의 번호를 기준으로 매칭하며, 공통 이미지는 회차 등록 시 기존 공유 업로드 경로를 사용한다.
- 회차형은 부모 도서를 저장하고 기존 회차 등록기로 연결한다. 부모 공개 및 회차 공개는 기존 서버 규칙을 유지한다.
- 추가정보는 접힌 상태로 시작한다. 기존 도서와 번역 연결은 변경하거나 이동하지 않는다.
- UI는 Quiz_Site의 GeneralBookManager, 기존 저장은 WorkEditor를 재사용한다.

## 일반도서 등록 UX 정리 (2026-10-31)

- 여러 원고의 등록 방식 명칭: **한 작품으로 묶기 / 여러 책으로 각각 등록**.
- 정보 화면의 이미 선택한 대표 표지·본문은 확인용으로 표시하고 변경 업로더는 접어 둔다. 언어별 대표 표지와 회차 공통 삽화는 별개다.
- 일반도서의 묶음 회차는 `UnifiedWorkEpisodes`에서 번호별 한 행으로 한국어·영어·일본어 자료와 공통 공개일을 관리한다. 언어별 저장 버튼은 없으며 작품 정보와 회차를 **전체 임시 저장 / 전체 저장하고 예약·공개**로 처리한다.
- 시작 일시·간격은 번호순으로 세 언어에 공통 적용한다. 서버 저장은 한국 시간 `+09:00`이며 즉시 공개로 바꿀 때 `releaseAt`과 `releaseDate`를 모두 비운다. 단권 도서도 세 언어에 공통 공개일을 적용한다.
- 다시 열면 서버에 임시 저장한 회차·원고·삽화·공개일을 불러온다. 기존 언어별 일정이 다르면 자동 통일하지 않고 명시적으로 공통 날짜를 선택하게 한다.
- 일부 실패 시 성공한 항목의 ID·revision·업로드 결과를 보존하고 재시도한다. 여러 언어의 서버 호출 전체가 하나의 원자적 트랜잭션인 것은 아니다. 회차의 언어별 저장이 모두 성공한 뒤 공개를 시도하며 실패 상태는 화면에 남는다.
- 회차 초안 삭제 및 작품의 모든 언어 초안 삭제 제공. 작품 삭제는 자식 회차를 먼저 확인하고 삭제한 뒤 부모를 삭제한다. 공개 이력이 있는 작품·회차는 초안 삭제에서 제외한다. 서버도 `draftOnly`로 재검사한다.
- 월간호 기존 편집기는 그대로 유지한다. 일반도서 편집기를 공통화했으며 앱 바이너리 변경은 없다.
- 적용 순서: Functions의 `reader` 배포 → Quiz_Site 커밋·푸시/웹 배포(사용자 수행). 실제 운영 자료 생성·삭제 검증은 수행하지 않았다.

## 회차 목록과 저장 진행 확인 (2026-10-31)
- 회차별 한 줄 목록: 회차 / 한국어 / 영어 / 일본어 / 공통 공개일 / 진행 상태.
- 제목과 언어별 상태를 기본 표시하고, 파일·제목 수정은 펼침 영역에 둔다.
- 상단 고정 영역에서 이번 작업의 완료·처리 중·대기·실패 회차 수를 확인한다.
- 실제 요청에 맞춰 저장 중 → 원고 업로드 중 → 삽화 업로드 중 → 공개 처리 중을 표시한다.
- 임시 저장 / 공개 예약 / 공개 중을 구분한다. 공개 상태는 저장된 공개 스냅샷 기준이며 예약 시간이 지나면 표시도 갱신한다.
- 일부 언어 실패 시 오류를 표시하고 성공한 파일·저장 결과를 보존한다. 같은 화면에서 재시도하면 완료된 언어를 다시 저장·업로드하지 않는다.
- 처리는 브라우저에서 진행한다. 처리 중 화면을 닫거나 다른 관리자 페이지로 이동하지 않는다. 다른 탭 작업은 가능하다.
- 검증: 파일·일정·상태·재시도 테스트 26개 및 웹 프로덕션 빌드. 로컬 독립 화면에서 실제 컴포넌트와 모의 API로 일부 실패 → 재시도 → 공개 완료 확인. 운영 데이터 저장·공개는 수행하지 않았다.

## 쿠피 어드민 전체 검수 — 2026-10-31
검수 범위: 일반도서·일반소설·연재·월간 쿠피·글꼴의 코드, 메뉴/권한, 파일 연결, 저장/공개/삭제 경로, 서버 인증·revision 검사·회차 중복 방지.

수정 사항:
- 기존 번역본 연결 후 통합 회차 목록을 다시 구성해 새로 연결된 언어의 저장된 회차를 읽는다. 회차 미저장 입력이 있으면 연결을 막는다.
- 대표 표지와 월간 회차 이미지의 성공한 업로드를 기억해, 다른 언어 실패 후 재시도 시 공통 이미지가 언어별 이미지를 덮거나 성공한 이미지가 재업로드되지 않게 한다. 완료된 선택의 미리보기도 실제 저장 상태에 맞춘다.
- 통합 회차의 기존 공통 삽화는 새 공통 삽화로 교체 가능하다. 동일 hash 재시도는 연결 요청을 생략하고 언어별 삽화는 보존한다.
- 월간 기존 회차를 열면 저장된 공통 공개 일시를 상단에 표시한다. 언어별 일정이 다르면 공통 칸을 비워 오인하지 않게 한다.
- 언어마다 원고가 한 개여도 번호가 서로 다르면 여러 원고로 판단하여 한 권으로 조용히 묶지 않는다.
- 메뉴 링크·프로젝트 전환·로그아웃 및 새로고침에 공통 이탈 방지를 적용한다. 저장 중 이동을 막고, 미저장 입력은 확인한다. 브라우저 뒤로가기 등 모든 종류의 SPA 이동을 가로채는 구현은 아니다.
- 언어 선택 변경도 미저장 상태로 기록하며 도서 저장의 중복 실행을 막는다.

검증 범위와 제한:
- 웹 회귀 테스트 27개, 서버 단위 테스트 48개 및 웹 프로덕션 빌드.
- 실제 WorkEditor 컴포넌트와 모의 API로 한국어 전용 표지 + 공통 표지, 일본어 공개 1회 실패 후 재시도를 점검한다.
- 운영 데이터 수정·삭제·공개, 실 Firebase 업로드, 실제 예약 시각 도달 및 월말 자동 합본 스케줄러 실행은 이번 검수에서 수행하지 않는다.
- 요청 처리 후 응답 자체가 유실된 경우에는 관리자 API 안내대로 목록을 다시 열어 서버 저장 여부를 확인해야 한다. 임의로 성공을 가정하거나 자동 재전송하지 않는다.
- 이번 추가 수정은 웹 프로젝트에 있으며 커밋·푸시는 소유자가 진행한다. 기존 서버 변경분의 배포 여부는 별도로 확인해야 한다.

## 공개 작품·회차 삭제 복원 — 2026-10-31
- 이전 통합 화면의 초안 전용 삭제 제한을 제거했다. 공개 작품도 하단 ‘삭제 관리’에서 언어별 또는 전체 언어 삭제가 가능하다.
- `ReaderDeleteActions`를 일반도서·소설 통합 편집, 월간호 설정, 월간 단일 회차 편집에서 공유한다. 일반도서 통합 회차 행에는 ‘회차 삭제’를 표시한다.
- 작품 삭제는 모든 대상 회차 목록을 먼저 확인하고, 작품/회차 개수를 확인창에 표시한 후 회차 → 상위 작품 순서로 처리한다. 연결된 합본 도서는 별도 항목이며 함께 삭제하지 않는다.
- 영구 삭제는 복구할 수 없으며 이미 사용자가 내려받은 기기 파일은 유지된다. 실제 운영 콘텐츠는 이번 작업에서 삭제하지 않았다.
- 중간 실패 시 재시도 안내를 표시한다. 파일 정리가 덜 된 deleting 항목도 목록에서 숨기지 않는다. 서버의 기존 revision·삭제 재시도 처리를 그대로 사용한다.
- 상위 작품 작업 중 회차 저장을 동시에 실행하지 않도록 상위 busy 상태를 전달한다.
- 삭제 범위·순서·부분 실패·언어별 선택 회귀 테스트를 포함해 웹 테스트 31개와 프로덕션 빌드로 검증한다. 서버 코드 변경은 없다.

## 일반 도서 목록 대표 표지 — 2026-10-31
- 목록의 왼쪽에 대표 표지, 오른쪽에 제목·도서 유형·언어별 상태를 배치한다. 작은 화면에서도 이미지 왼쪽 배치를 유지한다.
- 한국어 표지가 있으면 우선 사용하고, 없으면 다른 등록 언어의 표지를 사용한다. 이미지 비율은 contain으로 유지한다.
- 표지 없음·로딩·불러오기 실패를 구분한다. 화면 근처 항목만 요청하고 만료 전 미리보기 URL은 재사용한다.
- `ReaderSavedCover.tsx`는 저장된 표지를 표시한다. `readerAdmin?action=coverPreview`는 기존 관리자 인증·superAdmin 검사 후 저장된 cover만 5분 유효 URL로 제공한다. 공개 여부와 관계없이 관리자 초안 표지를 확인할 수 있다. 공개 Catalog나 Storage 규칙을 완화하지 않는다.
- 서버 정책 테스트 51개, 웹 빌드 통과. 실제 목록·상위 레이아웃 컴포넌트에 모의 API와 기존 샘플 표지를 사용하여 1440px/390px 배치, 표지 없는 항목, 편집 진입을 검수했다. 운영 서버의 신규 API는 배포 후 확인이 필요하다.
