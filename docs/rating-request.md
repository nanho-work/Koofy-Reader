# 누적 독서 시간 기반 평가 요청

- Android와 iOS의 공식 인앱 평가 API를 `in_app_review`로 호출한다.
- 실제 네이티브 독서 화면이 준비된 뒤 활성 상태인 시간만 누적한다. 백그라운드 진입과 독서 종료 시 중단한다.
- 30초마다, 백그라운드 진입 및 종료 시 기기에 저장한다. 강제 종료 시 마지막 저장 이후 최대 약 30초가 누락될 수 있다.
- 첫 요청 기준은 누적 5시간이다. 과거 버전에서 읽은 시간은 소급 추정하지 않는다.
- 독서 화면에서 서재로 돌아오고 전환이 끝난 뒤 요청한다. 그 사이 다른 화면으로 이동하거나 앱이 비활성화되면 요청하지 않는다.
- 마지막 요청 시도부터 최소 90일이 지나야 다시 요청한다. 중복 호출은 직렬화하고, 시도 기록을 먼저 저장한다.
- OS가 평가창을 표시했는지, 이용자가 별점이나 리뷰를 제출했는지는 판단하지 않는다. 요청에 실패하더라도 90일 제한은 유지한다.
- 설정의 ‘평가 남기기’는 누적 시간과 무관하게 스토어 평가 페이지를 연다. 자동 평가 요청의 노출 한도에 의존하지 않는다.
- 만족도 선별 질문, 긍정 리뷰 유도, 리뷰 대가 보상은 없다.

누적 시간과 요청 시각은 SharedPreferences의 `reader_review_usage_v1`에 저장한다. Analytics 동의 여부와 독립적으로 동작하며 이 기록을 서버에 전송하지 않는다. 앱 삭제·데이터 초기화 시 기록도 초기화될 수 있다.

한국어·영어·일본어 설정 문구를 제공한다. 앱 내 개인정보처리방침에도 로컬 기록을 안내했다. 다음 출시 전 공개 웹 방침에 동기화해야 한다.

검증 시 5시간을 실제로 기다릴 필요 없이 서비스 테스트에서 누적 시간을 주입한다. 실제 평가창 노출은 스토어·계정의 제한에 따라 달라진다. Android는 Play를 통해 설치한 앱으로 확인하고, iOS TestFlight에서는 자동 평가 요청이 표시되지 않을 수 있다.
