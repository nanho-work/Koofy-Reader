# 기본 소설과 다운로드 콘텐츠 언어

## 노출 규칙

- 앱에서 선택한 언어를 우선 적용한다.
- 자동 설정이면 기기의 첫 번째 설정 언어를 사용한다. 한국어·영어·일본어 외 언어는 영어로 처리한다.
- 기본 소설과 다운로드 도서/연재 목록에는 해당 언어만 표시한다. 글꼴 목록은 언어로 제한하지 않는다.
- 이미 다운로드하거나 직접 가져온 책은 언어를 바꿔도 유지한다.
- 기존 앱은 언어 파라미터를 보내지 않으므로 서버에서 한국어 목록을 돌려준다. 영어·일본어 자동 노출은 새 앱 배포가 필요하다.

## 기본 제공 소설

한국어 `sample_mermaid_001`, 영어 `sample_mermaid_001_en`, 일본어 `sample_mermaid_001_ja`는 독립된 책 ID다. 각 언어의 읽던 위치·책갈피·삭제 상태가 섞이지 않는다. 기본 책 목록만 바뀌며 저장된 독서 기록은 삭제하지 않는다.

영어·일본어 1화 본문과 표지는 `assets/books/sample_mermaid_001_en.*`, `sample_mermaid_001_ja.*`에 포함한다. 원문 파일에 안내문을 덧붙이지 않고 EPUB 생성 시 마지막 안내 페이지를 해당 언어로 추가한다.

## 서버 및 관리자

`readerContent`와 공개 스냅샷에 `language: ko | en | ja`를 저장한다. 없는 기존 데이터는 한국어로 취급한다. 회차는 부모 연재 작품의 언어를 상속한다.

- `readerCatalog?kind=book&supportsTxt=1&supportsSeries=1&language=en`
- 회차 조회에도 같은 언어와 `seriesId`를 보낸다.
- 공개된 스냅샷의 언어로 필터링한다. 필터 후 빈 페이지여도 원본 커서를 유지하여 다음 페이지를 읽는다.
- 공개 후 언어 변경은 금지한다. 번역은 별도 작품으로 등록한다.
- 다운로드 URL은 공개 여부와 버전을 검사한다. 언어 변경 자체로 기존 책의 다운로드를 차단하지 않는다.

관리자 웹 변경 파일은 별도 `Quiz_Site` 저장소의 `lib/admin/firebase/reader-api.ts`, `components/admin/reader/ReaderContentManager.tsx`다. 소유자가 커밋·푸시하여 웹을 배포해야 언어 선택 UI가 반영된다.

## 2026-10-21 자료 반영

원본은 Downloads 아래 `소설/인어공주는 파도를 벤다` 폴더다. 영어·일본어는 `번역/en`, `번역/ja`의 TXT/JPG 각 40쌍을 사용한다. 번역 검수 파일의 원문·번역 SHA-256을 실제 파일과 대조했다.

- 한국어 1~4화와 기존 한국어 표지는 유지한다.
- 한국어 5~40화 본문을 수정본으로 갱신한다.
- 영어·일본어 작품을 각각 만들고 1~40화 본문과 표지를 등록한다.
- 언어 필터 서버를 먼저 배포하고, 파일을 업로드한 다음 콘텐츠 메타데이터를 단일 트랜잭션으로 공개한다.

실행 도구: `tool/publish_novel_translations.cjs`. 기본 실행은 계획만 생성하며 `--apply`일 때만 업로드·공개한다. 성공한 공개를 중복 실행하면 중단한다. 기존 번역본 수정은 새 백업과 검토를 거쳐 별도로 진행한다.

로컬 작업 기록은 Git에서 제외된 `work/novel-localization-20261021/`에 보관한다.

- `before.json`: 변경 전 전체 콘텐츠 문서
- `manifest.json`: 입력 파일 경로와 해시
- `publication-plan.json`: 변경 예정 콘텐츠와 버전
- `published.json`: 공개 성공 기록
- `verification.json`: 운영 API의 언어별 목록 및 다운로드 검사 결과

기존 Storage 객체는 삭제하지 않는다. 되돌리기가 필요하면 백업과 현재 revision을 비교하여 해당 콘텐츠만 복원해야 하며 전체 데이터베이스를 덮어쓰지 않는다.
