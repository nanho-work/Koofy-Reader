# 쿠피 UI 개선 — 2026-09-19

승인된 서재·독서 설정 시안을 현재 Readium 기반 앱에 적용한다. 독서 엔진, 브리지 프로토콜, Locator 형식, 기록 저장·복원 흐름은 유지한다.

## 공통 테마

색상의 원본은 `design/reader_palette.json` 하나다. `python3 tool/generate_reader_palette.py`가 Flutter, Kotlin, Swift 팔레트를 생성하며 `--check`로 생성물의 일치를 검증한다. 생성 파일을 직접 수정하지 않는다.

- 앱 기본 밝은 테마는 종이색, 시스템 다크 모드는 어두운 테마다.
- 서재·앱 설정·광고 컨테이너·광고 로딩/오프라인/오류 안내·SafeArea는 동일한 앱 배경을 사용한다.
- 네이티브 독서 화면은 저장된 독서 테마를 사용한다. Readium의 공개 backgroundColor/textColor 설정과 헤더·푸터·화면 바깥 여백·시스템 바를 같은 팔레트에 연결했다.
- 보기 설정과 목차도 독서 테마를 따른다. 카드와 선택 항목에는 공통 보조 배경을 사용한다.
- 광고 소재 자체의 색상은 광고 제공사가 결정한다. 네이티브 전체 화면 리더에는 이번 패치로 광고를 새로 추가하지 않는다.

## 화면 구성

- 서재: KOOFY/내 서재 헤더, 이어 읽기 카드, 나의 책, 기존 검색·필터·정렬·가져오기 기능. 큰 인사 문구를 줄여 이어 읽기와 책 목록을 앞에 배치했다.
- 책 카드: 접힌 화면과 펼친 화면 모두 한 줄에 3권씩 표시한다. 좁은 카드에서는 더보기를 표지 오른쪽 아래로 배치하여 제목 영역의 폭을 확보한다. 표지와 제목 영역을 유지하고 작가와 읽기 상태를 함께 표시한다. EPUB 표지 추출과 새로운 목록 보기 기능은 이번 범위에 포함하지 않는다.
- 펼친 서재: 기존 힌지 회피, 좌우 영역, 필터와 스크롤 위치 보존을 유지한다.
- Android 보기 설정: 화면 아래에 표시되는 폭 제한 패널. 글자 크기, 배경, 읽기 방식, 페이지 배치를 그룹화하고 선택 상태를 표시한다. 작은 높이에서는 스크롤할 수 있다.
- iOS 보기 설정: 작은 화면에서는 높이 조절 가능한 시트, 넓은 화면에서는 버튼에 연결된 팝오버. 적용 중에는 중복 변경을 막고, 위치 복원 완료 후 같은 패널에서 다시 조절할 수 있다.
- 본문 중앙 탭: 헤더·푸터 메뉴를 표시하거나 숨긴다. 가장자리 페이지 이동은 기존 Readium 동작을 따른다.

## 읽던 위치 보호

메뉴 숨김은 Android `INVISIBLE`, iOS alpha/접근성 숨김으로 처리하여 **본문 viewport와 safe-area 크기를 유지**한다. 따라서 메뉴를 표시할 때와 숨길 때 본문이 다시 나뉘지 않는다. 메뉴를 숨긴 자리는 본문과 같은 단색 여백이다.

글자 크기와 페이지 배치 변경은 기존 네이티브 apply 경로로 전달한다. 공통 테마 적용을 위해 새로운 페이지 계산 또는 별도 위치 저장 코드를 만들지 않는다.

## 검증

Flutter 분석 통과, Flutter 테스트 76개·Android instrumentation 10개·iOS XCTest 6개 통과. Android debug APK와 iOS simulator 앱 빌드 성공.

- Flutter: 서재 검색·필터·이어 읽기·폴더블·큰 글자 회귀 테스트, 앱 설정과 오프라인 광고 영역의 밝은/어두운 배경 일치.
- Android: 실제 WebView에서 세 테마의 CSS 배경과 네이티브 배경 일치, 중앙 탭 전후 viewport/Locator 보존, 기존 두 페이지·반복 재개방·문자 위치 회귀.
- iOS: 실제 WKWebView에서 테마와 메뉴 표시 전후 위치 보존, 보기 설정을 열고 선택한 뒤 패널이 유지되는 흐름, 기존 반복 재개방 회귀.
- Android 16 대화면에서는 앱의 방향 고정 요청이 무시될 수 있어 테스트는 실제 사용 가능 너비를 기준으로 두 페이지를 검증한다.

로그와 캡처는 `work/ui-*`에 보관한다. 실제 폴더블의 물리적 접기/펼치기는 연결된 기기가 없어 이번 시뮬레이터 검증에 포함하지 않는다.
