# 묶음 독서와 백업 (2026-09-24)

- 제목순 정렬은 숫자 묶음을 비교한다. 예: 제1화, 제2화, 제10화. 새 묶음과 추가할 책의 선택 목록에도 적용한다.
- 묶음의 저장된 순서는 유지한다. 상세 화면의 정렬 버튼만 저장 순서를 바꾸며, 손잡이로 수동 순서를 지정할 수 있다.
- 묶음 내부 표지는 기본 숨김. `showMemberCovers`를 묶음별로 저장한다. 서재 대표 표지에는 영향을 주지 않는다.
- 다음 권은 현재 묶음의 저장 순서로 결정한다. 네이티브 리더에 다음 제목을 전달하고, 확인 후 `closed` 체크포인트로 현재 책을 저장한 다음 동일 Flutter 경로에서 다음 책을 연다. 마지막 권에는 버튼이 없다. 자동 완독 처리는 하지 않는다.

## 백업

설정 → 서재 백업·복원에서 파일 앱으로 `.koofy.zip`을 저장/선택한다.

- 포함: TXT/EPUB 원본, 개인/묶음 표지, 묶음 순서와 표지 표시 여부, 읽던 위치(내용 버전 포함), 책갈피, 완독, 보기 설정.
- 제외: 광고 보상, 광고 동의, 계정/인증 정보, 다운로드 글꼴 바이너리, 폐기된 구형 리더 기록.
- 읽은 책은 파일 선택기의 임시 원본이 사라졌더라도 해시 검증된 앱 보관본을 사용한다.
- 현재 책/묶음/독서 기록이 있으면 보존하고 없는 자료를 병합한다. 보기 설정은 기존 전역 설정이 없을 때만 복원하며 다운로드 글꼴 선택은 기본 글꼴로 바꾼다.
- 기존 묶음에 속한 책은 새 묶음에 중복 편입하지 않는다. 동일 백업을 재시도해도 책/그룹 ID가 중복 생성되지 않는다.
- ZIP 저장/해제는 별도 isolate에서 수행한다. 합계 100 MiB, manifest 5 MiB, 파일 4,001개 한도를 둔다. 경로/형식/중복/크기/SHA-256을 검증하고 임의 경로로 추출하지 않는다.
- 네이티브 미확인 체크포인트를 먼저 회수한다. 복원 세션 ID는 새로 할당하며 기존 독서 기록은 덮어쓰지 않는다. 메타데이터 쓰기 실패 시 SQLite 트랜잭션과 변경한 환경설정을 되돌린다. 강제 종료/저장 공간 부족 시에도 참조될 수 있는 복원 파일을 지우지 않으며 원본 백업으로 재시도할 수 있다.

## 실기기 확인

1. 1·2·10화로 묶음을 만들고 숫자 정렬, 수동 정렬, 표지 표시 스위치를 재실행 후 확인한다.
2. Android/iOS 독서 화면에서 다음 권을 열고, 이전 책의 위치와 다음 책의 설정/이어읽기를 확인한다.
3. 파일 앱/클라우드 저장소로 백업하고 새 설치 환경에서 복원한다. 표지·묶음·진행률을 확인한다.
4. 같은 백업 재복원, 취소, 손상 파일, 저장 공간 부족, 원본 캐시 만료를 확인한다.
