# 책 읽어주기 구현 기록

작성일: 2026-09-25. 이 문서는 현재 작업 트리의 구현 기록이다. 스토어 배포 완료를 뜻하지 않는다.

## 제공 동작

- 독서 설정 아래 오른쪽 위의 48dp/pt 재생·일시정지 버튼. 배경에만 불투명도 40%를 적용하고 아이콘은 선명하게 유지한다. 독서 메뉴를 숨기면 같이 숨긴다.
- 재생 중 기존 하단 진행 표시 자리에 이전 문장·다음 문장·듣기 설정을 표시한다. 듣기 설정은 독서 설정 또는 재생 버튼 길게 누르기로도 연다.
- 설치된 로컬 한국어 음성 선택·미리 듣기, 속도 0.75/1/1.25/1.5/2배, 문장 강조와 따라가기, 취침 타이머 사용 안 함/15/30/60분.
- TXT가 변환된 내부 EPUB과 기존 DRM 없는 리플로우 EPUB에 같은 Readium 본문 경로를 사용한다. 처음 재생은 독서 위치, 일시정지 후 재생은 듣던 문장 시작부터다.
- 홈·잠금·다른 앱·서재 이동·오디오 포커스/세션 중단·이어폰 분리·광고 클릭/확장 시 멈춘다. 복귀나 포커스 회복으로 자동 재생하지 않는다. 배너 표시만으로는 멈추지 않는다.
- 직접 페이지·목차·검색 결과로 이동하면 새 독서 위치를 다음 재생 기준으로 삼는다. 글꼴/레이아웃 변경과 회전·접힘에서는 듣던 문장을 유지하며 정지한다.
- 책 끝에서 멈춘다. 다음 묶음도서 자동 재생, 백그라운드 음성 서비스, 잠금 화면 조작, 마이크 입력은 추가하지 않았다.

## 구성과 저장 경계

| 구분 | 담당 |
| --- | --- |
| Android ReaderSpeech | Readium 3.1.2 TtsNavigator, 초기화·재생 작업 취소, 오디오 포커스, 문장 위치, 전역 음성 설정 |
| Android OfflineSpeechEngine | OS TextToSpeech, 매 요청마다 오프라인 설치 음성 명시, 긴 발화 분할, 늦은 콜백 무효화 |
| iOS ReaderSpeech | Readium 3.11.0 PublicationSpeechSynthesizer/AVTTSEngine, 설치된 AVSpeechSynthesisVoice 명시, AVAudioSession 전경 정책 |
| 양 플랫폼 SpeechStart | CSS/fragment 앵커를 본문 요소로 정규화하고 요소 안의 문장 위치를 찾는다. 앞 문장은 실제 음성 엔진으로 보내지 않는다. |
| ReaderActivity / KoofyReaderViewController | 버튼·독서 위치 연결, 생명주기·광고·수동 탐색 중단, 문장 따라가기 |
| ReaderSpeechDialog / ReaderSpeechSettingsViewController | 플랫폼별 듣기 설정 UI |

Flutter/Pigeon 계약과 Drift 스키마는 바꾸지 않는다. 전역 목소리·속도·따라가기 설정과 책별 듣던 위치는 Android `reader_speech` SharedPreferences, iOS `reader.speech.*` UserDefaults에 저장한다. 타이머는 현재 독서 세션에만 적용한다.

음성 위치는 책 ID, contentRevision, Readium Locator 및 문단 내 문장 순번 `koofySpeechOrdinal`로 저장한다. 반복되는 문장도 순번으로 구분하며 본문 리비전이 바뀌면 예전 위치를 사용하지 않는다. 기존 독서 위치 DB에 음성 위치를 직접 쓰지 않는다. 따라가기를 켜면 화면 자체가 이동하므로 일반 독서 체크포인트에는 이동한 화면 위치가 기록된다.

음성 설정과 듣던 위치는 현재 `.koofy.zip` 서재 백업 범위에 포함되지 않는다. 앱 삭제 후 별도로 복원되지 않는다. 사용방법 안내에도 이를 명시했다. 서버 전송·클라우드 TTS API·사용량 과금 연동을 추가하지 않았다. 음성 다운로드에는 기기 설정과 네트워크가 필요할 수 있다. 합성 품질과 음성 제공은 기기의 엔진 및 설치 음성에 달려 있다.

## SDK 연결 시 주의점

1. Readium 콘텐츠 탐색은 문단 내부의 표시 문장까지 자동으로 찾아주지 않는다. `SpeechStart`와 실제 TTS가 같은 문장 분리 규칙을 사용해야 한다. Android는 양쪽 모두 한국어 Sentence tokenizer로 고정했다. 저장된 순번이 없으면 앞뒤 인용문으로 문장을 찾는다. 동일한 문맥이 반복되거나 복잡한 인라인 노드가 있는 EPUB의 최초 시작점은 추가 실기기 검증 대상이다.
2. Android 3.1.2에서 `navigator.go()`와 `play()`를 연달아 호출하면 별도 비동기 작업이 겹치며 발화 시작이 중복될 수 있다. 새 독서 위치/저장 위치로 시작할 때는 해당 Locator로 navigator를 생성하고 바로 재생한다. 같은 세션의 일시정지 재개는 유지한 커서를 사용한다.
3. Android 3.1.2 Media3 어댑터는 `handleAudioFocus=false`를 반영하지 않고 일시 포커스 손실 후 재개할 수 있다. 어댑터에만 포커스를 요청하지 않는 `USAGE_VOICE_COMMUNICATION_SIGNALLING`을 설정한다. 실제 TextToSpeech 출력은 MEDIA/SPEECH이고 ReaderSpeech가 명시적으로 포커스를 관리한다. Readium 업데이트 시 이 호환 처리를 다시 검증한다.
4. iOS의 Readium 자동 AudioSession 관리 대신 ReaderSpeech가 전경 상태에 맞춰 활성화/해제를 소유한다. 오래된 synth 상태 콜백은 인스턴스와 작업 세대로 차단한다.
5. Android 음성은 `isNetworkConnectionRequired=false`이며 미설치 표시가 없는 항목만 허용한다. 명시한 음성이 없으면 오류를 안내하고 언어 기반 기본/네트워크 음성으로 대체하지 않는다. iOS도 설치된 한국어 음성 ID를 확인한다. 제삼자 OS 엔진의 메타데이터 정확성을 앱이 독립적으로 보증하는 구조는 아니다.
6. Android 긴 발화는 3,000 UTF-16 코드 단위 이하로 나누되 서로게이트 쌍을 유지한다. 문장 강조는 프레임/단어마다 화면을 이동하지 않고 실제 발화 문장이 바뀔 때 갱신한다.

## 확인한 범위

- Flutter 기존 자동 테스트: 191개 통과.
- `flutter analyze lib test packages/koofy_reader_bridge/lib pigeons`: 문제 없음.
- 전체 루트 분석은 기존 `work/` 실험·템플릿 파일의 문제 10개 때문에 통과하지 않는다. 이번 TTS 코드와 별개다.
- Android API 36 에뮬레이터 계측 테스트 6개: 오프라인 음성 필터, 긴 문자열 분할, 초기화 중 이탈, 현재 문단부터 시작/백그라운드·포커스 중단/자동 재개 금지/독서 체크포인트 분리, 긴 문단의 중간 문장·반복 문장 이어 듣기, 기존 페이지 이동·글꼴 변경 복원.
- Android 테스트는 Readium 본문·탐색·오디오 포커스를 실제로 사용하지만 발화 엔진은 제어 가능한 가짜 엔진이다. 실제 목소리 합성·음질을 검증했다는 뜻이 아니다. 재생 버튼과 하단 조작부는 에뮬레이터 캡처로 확인했다.
- iOS 기기용 debug 빌드 성공(서명 제외). iOS 런타임·실기기 음성 테스트는 미실시.

## 실기기 합격 기준

1. Android/iPhone에 한국어 음성을 설치한 후 비행기 모드에서 TXT/EPUB 재생·미리 듣기·음성 변경을 확인한다. 음성이 없거나 삭제되면 안내하고 멈춰야 한다.
2. 긴 문단 중간에서 시작 → 일시정지 → 재개 → 이전/다음 문장 → 서재 복귀 후 저장된 듣던 위치 재생. 문장이 건너뛰거나 문단 처음으로 돌아가면 안 된다.
3. 홈·화면 잠금·전화·다른 음악 앱·유선/블루투스 해제·광고 클릭으로 즉시 멈추고, 복귀 후 직접 재생하기 전에는 소리가 나지 않아야 한다.
4. 연속 스크롤/즉시 넘김/책장 넘김, 한쪽/양쪽 페이지, 회전·접힘, 큰 글씨, 어두운 테마에서 버튼 접근·수동 페이지 이동·듣던 위치 유지와 따라가기를 확인한다.
5. 타이머 종료, 마지막 문장, 음성 엔진 오류, 빠른 재생/정지 반복, 준비 중 서재 이탈에서 중복 재생·늦은 자동 시작이 없어야 한다.
6. 긴 TXT·큰 EPUB에서 시작 지연과 메모리를 측정한다. 현재 실제 기기 성능 수치는 측정하지 않았다.

## 되돌리기

TTS 전용 파일과 호스트/광고/메뉴의 TTS 연결을 이 변경 단위로 되돌린다. Android TTS 의존성·queries 및 안내서도 함께 되돌린다. 기존 서재·본문·체크포인트 스키마는 변경하지 않아 데이터 마이그레이션 역변환은 필요 없다. TTS 전용 로컬 설정이 남아도 이전 버전 독서에는 사용되지 않는다. 다른 작업의 미커밋 버전·배포 기록을 포함해 작업 트리 전체를 reset하지 않는다.
