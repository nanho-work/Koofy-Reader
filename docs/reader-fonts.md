# 리더 글꼴 적용

2026-09-20. Android Readium 3.1.2 / iOS Readium 3.11.0의 EPUB 본문 글꼴 기능이다. 앱 전체 UI 글꼴은 바꾸지 않는다.

## 사용자 동작

책을 열고 **보기 → 맨 아래 글꼴**에서 선택한다. 설정 순서는 글자 크기 → 배경 → 읽기 방식 → 페이지 배치 → 페이지 전환 효과 → 글꼴이다.

| 표시 이름 | 저장 ID | 파일 / 굵기 |
| --- | --- | --- |
| 기본 | `default` | 책에서 지정한 글꼴과 엔진 기본값 |
| 메이플스토리 | `maplestory` | Light 300 / Bold 700 |
| 학교안심 시간표 | `hakgyoansim-siganpyo` | Regular 400 |

메이플스토리는 메뉴에서 하나의 글꼴이다. 일반 본문은 Light를 사용하고, 책의 굵은 강조는 Bold를 사용한다. 학교안심 시간표는 제공된 Regular 한 파일을 사용하며 굵은 강조는 WebView가 합성할 수 있다. 없는 문자는 대체 글꼴로 표시한다.

선택은 읽기 위치와 함께 책별로 저장한다. 다른 글꼴을 선택하면 줄바꿈과 페이지 수는 달라질 수 있지만, 읽던 문장의 정확한 위치를 복원한다. 글꼴 로드와 레이아웃이 안정된 뒤 위치를 확정한다. 책장 넘김 미리보기에도 같은 글꼴 선언을 적용하고, 글꼴 변경 시 기존 이미지 캐시를 버린다.

## 원본과 패키징

원본은 프로젝트의 `assets/fonts/`에 유지한다.

- `Maplestory OTF Light.otf`
- `Maplestory OTF Bold.otf`
- `Hakgyoansim_SiganpyoOTFR.otf`
- `catalog.json`: 글꼴 ID, 표시명, CSS 별칭, 굵기, 파일별 SHA-256

원본 파일은 수정하거나 변환하지 않았다. 세 OTF의 총 크기는 1,964,152바이트(약 1.87 MiB)이다.

Android Gradle은 이 폴더를 네이티브 assets로 묶는다. iOS는 `packages/koofy_reader_bridge/ios/Resources/Fonts/`의 **개별 상대 심볼릭 링크**를 통해 같은 원본을 CocoaPods 리소스 번들에 넣는다. 폴더 전체 심볼릭 링크는 CocoaPods 리소스 검색에서 누락될 수 있어 사용하지 않는다. 새 파일을 추가하면 catalog와 해당 iOS 파일 링크도 함께 추가한다.

Flutter `pubspec.yaml`의 `fonts:` 등록은 필요하지 않다. 실제 본문은 Flutter Text가 아니라 네이티브 Readium WebView가 렌더링한다.

## 설치와 렌더링

책을 열 때 작업 스레드에서 카탈로그를 읽고 다음 앱 전용 저장소를 준비한다.

- Android: `filesDir/reader-fonts/v1/<sha256>.otf`
- iOS: `Application Support/KoofyReader/fonts/v1/<sha256>.otf`

캐시가 유효하면 다시 복사하지 않는다. 누락되거나 체크섬이 다르면 번들의 OTF 헤더와 SHA-256을 확인한 후 원자적으로 교체한다. 사용하지 않는 글꼴을 WebView에 미리 로드하도록 지정하지 않는다.

Android는 Readium `CompositeContainer`에 허용된 로컬 글꼴 리소스만 추가한다. Readium의 동일 출처 리소스 서버가 이를 제공하므로 `file://` 접근이나 외부 폰트 서버를 열 필요가 없다. iOS는 `CSSFontFace(file:)`와 `fontFamilyDeclarations`를 사용한다. 본문과 미리보기는 동일한 설정 생성 함수를 공유한다.

설정 `fontId`는 Pigeon → 네이티브 복구 저널 → Flutter DB 경로에 포함한다. 예전 기록에 필드가 없으면 `default`로 해석하며 DB 스키마 변경은 필요 없다.

## 검증

- Flutter 테스트 84개 통과, 정적 분석 오류 없음.
- Android API 36 에뮬레이터: 네이티브 테스트 19개 통과. 추가로 넓은 화면에서 사용자 글꼴을 적용한 두 페이지 넘김 및 반복 재진입 테스트 2개 통과.
- Android debug APK와 iOS 테스트 앱 빌드 성공. APK 내부 OTF의 SHA-256이 원본과 일치함을 확인했다.
- iOS 26.3 iPad 시뮬레이터: 자동 테스트 11개 통과. 기존 수동 손가락 제스처 probe 1개는 자동 실행 대상이 아니므로 건너뜀.
- 실제 FontFace 상태로 메이플스토리 300/700, 학교안심 400 파일 로드를 확인했다.
- 글꼴만 바꾸기, 기본 글꼴 복귀, 크기 변경, 스크롤 전환, 읽기 위치 보존, 책장 넘김 캐시 교체와 실제 다음 페이지 일치, 저널의 구버전 호환, 손상된 로컬 글꼴 복구를 검사했다.
- iOS 실제 본문과 보기 설정의 테스트 캡처를 확인했다.

실물 Android 폴더블/iPhone 테스트는 별도로 필요하다. 시뮬레이터 결과를 실물 기기 성능 측정으로 해석하지 않는다.

## 로컬 기기 확인

네이티브 코드와 리소스가 추가되어 Hot Reload만으로 적용되지 않는다. 기존 실행을 종료하고 `flutter run -d <기기 ID>`로 다시 빌드한다. iOS는 필요하면 `cd ios` 후 `pod install`을 실행한다. 앱 삭제는 필요 없다.

1. 기존 책을 열고 메이플스토리를 선택한다. 일반 글씨와 굵은 강조를 확인한다.
2. 학교안심 시간표로 바꾸고 크기를 조절한다. 읽던 문장이 화면에 남는지 확인한다.
3. 서재로 나갔다 이어 읽기: 선택한 글꼴과 읽던 위치를 확인한다.
4. 폴더블을 접고 펼쳐 한 페이지와 두 페이지로 확인한다.
5. 책장 넘김 효과에서 본문과 넘기는 장의 글꼴이 같은지 확인한다.
6. 기본으로 돌아가 책의 원래 글꼴로 복귀하는지 확인한다.

## 이후 다운로드 기능

이번 패치는 번들 폰트로 로컬 렌더링을 검증하는 단계다. 관리자 페이지, 서버, 다운로드 버튼은 포함하지 않는다. 이후에는 원격 카탈로그, 다운로드/삭제 상태, 서버 파일 검증과 버전 정책, 삭제된 글꼴의 복원 정책을 추가하고 현재의 고정 선택 목록/ID 검증을 카탈로그 기반으로 확장해야 한다. 설치된 로컬 파일을 Readium에 공급하는 부분은 재사용할 수 있다.
