# 쿠피리더 1.10.1 (22) 출시 기록

작성일: 2026-11-05. 사용자가 iOS·Android 빌드 후 양쪽 스토어 업로드와 심사 제출을 요청했다. Git 커밋·푸시는 사용자가 진행한다.

## 변경 내용

- 마지막 페이지에서만 다음 회차 읽기를 제공한다. 기기에 있는 다음 회차는 바로 열고, 공개된 다음 회차는 공통 확인창에서 다운로드에 동의하면 내려받아 바로 연다. 취소·오류 시 기존 독서 위치를 보존한다.
- 공개 예정 안내창에 작품 즐겨찾기와 알림 설정을 추가했다. 회차가 아닌 부모 작품을 저장하며 월간 쿠피는 코너 전체 즐겨찾기를 사용한다. OS 알림 거절과 관계없이 로컬 즐겨찾기는 유지한다.
- 한국어·영어·일본어를 함께 반영했다. 광고로 미리 읽는 기능은 포함하지 않는다.

## 검증과 파일

- 버전 1.10.1, 빌드 번호 22. Flutter 전체 테스트 447개, 앱 소스 정적 분석 통과.
- Android 서명 AAB와 iOS App Store 서명 IPA 생성 성공. Android Readium 서비스 식별자 7개 보존 검사 및 JAR 서명 검사 통과.
- iOS IPA 서명 검사 통과. Bundle ID `com.koofylab.koofyreader`, 버전·빌드 번호, APNs `production`, `get-task-allow=false`, 메시징 자동 초기화 꺼짐 확인.
- 앞선 debug 수정본은 Android 기기에 설치하고 사용자가 확인했다. 이번 release 파일 양쪽 실기기 동작을 모두 검증했다는 뜻은 아니다.
- 파일과 SHA-256, 검사 로그: `work/release/1.10.1-22/`.
- Android: `KoofyReader-1.10.1-22.aab`, iOS: `KoofyReader-1.10.1-22.ipa`.
- 출시 노트: `출시·홍보자료/출시노트/1.10.1/`의 한국어·영어·일본어. 기존 스토어 이미지·설명은 유지했다.
