# 쿠피리더 1.10.0 (21) 빌드와 출시 기록

작성일: 2026-11-05. 사용자가 Android와 iOS 빌드·게시, 독서 기록 소개 이미지 추가를 요청했다. Git 커밋·푸시, 웹·서버 배포는 사용자가 진행한다.

## 포함 내용

- 기기에 보관하는 독서 기록: 날짜별 읽은 책과 시간, 달력 및 일별·월별 그래프.
- 즐겨찾기와 새 글 알림 흐름, APNs 준비를 기다리는 iOS 알림 등록 처리.
- 도서 목록 캐시 우선 표시와 30분 갱신 기준. 예약 공개 시각에 맞춘 갱신은 유지한다.
- 공통 안내 팝업과 개인정보 설정 개선. 통계 기본 꺼짐·필수 UMP 절차·뷰어 전용 배너를 유지한다.
- 광고로 공개 예정 회차를 미리 읽는 기능은 이번 버전에 포함하지 않는다.

- 버전 `1.10.0`, 빌드 번호 `21`, 양쪽 앱 ID `com.koofylab.koofyreader`.
- Flutter 정적 분석 통과, 전체 테스트 433개 통과.
- 실제 Flutter 화면을 생성하는 스토어 캡처 테스트: 한국어·영어·일본어 통과.
- Android AAB 빌드 및 서명 검증 통과. Readium 식별자 7개 보존 검사 통과. Play 업로드에서 API 24 이상·대상 API 36·3개 ABI를 확인했다.

- 이번 출시 준비 중 양쪽 실기기 동작·실제 푸시 수신을 모두 검증한 것은 아니다. 앞선 iPhone 연결 확인과 자동 검사·출시 빌드 성공은 실제 푸시 도달 검증과 구분한다.

## 스토어 이미지와 문구

- `출시·홍보자료/제작원본/독서기록_추가이미지/manifest.json`에 18개 출력 이미지 목록이 있다.
- 언어별 휴대폰·태블릿·Duo 규격으로 독서 달력과 시간 그래프를 조판했다. 실제 앱 위젯에 예시용 로컬 독서 이력을 넣어 캡처했다. 운영 데이터는 변경하지 않았다.
- 기존 스크린샷은 유지하고 각 슬롯 마지막에 독서 기록 이미지 한 장을 추가했다.
- Google: 한국어·영어·일본어 각각 휴대전화·7인치·10인치 스크린샷 7/8장 확인.
- Apple: 한국어·영어·일본어의 iPhone·Duo·iPad 슬롯에 새 이미지가 저장된 것을 확인했다. 한국어 iPhone은 7장, Duo는 기존 3장에 한 장을 더한 4장이다. 슬롯마다 기존 이미지 수가 달라 총 장수가 같지는 않다.
- 앱 이름은 유지했다. 기존 EPUB·TXT·TTS·두 페이지·오프라인 소개에 독서 달력과 시간 기록 설명을 추가하고 Apple의 언어별 키워드를 갱신했다. 검색 순위나 특정 검색어 노출을 보장하지 않는다.
- 문구 원본과 이전 Google 설명: `work/release/1.10.0-21/store-copy.json`.
