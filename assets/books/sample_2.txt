이 설명서는 항목별로 나누어져 있습니다. 독서 화면의 ‘목차’를 열면 필요한 설명으로 바로 이동할 수 있습니다. 페이지 넘김에서는 각 설명이 새 페이지에서 시작하고, 긴 설명은 다음 페이지로 이어집니다.

‘책 가져오기’로 내 기기의 TXT·EPUB을 추가하거나, ‘도서·글꼴 다운로드’에서 제공되는 책을 내려받아 보세요. 책 표지를 누르면 독서 화면이 열립니다.

[장] 서재에서 책 찾기
‘이어 읽기’를 누르면 읽던 책의 저장된 위치에서 다시 시작합니다.
‘나의 책’ 아래에 항상 보이는 검색창으로 제목이나 작가 이름을 찾고, 필터와 ‘최근 읽은 순’·‘제목순’ 정렬로 목록을 정리할 수 있습니다.
책이 보이지 않으면 검색어와 필터를 확인하고 서재를 아래로 당겨 새로고침해 주세요.
제목순 정렬에서는 제목에 들어간 숫자를 구분해 1화·2화·10화 순서로 표시합니다.

[장] 내 파일 가져오기와 표지 등록
‘책 가져오기’에서 기기에 저장된 TXT 또는 EPUB 파일을 선택합니다. 여러 파일을 한 번에 선택할 수 있습니다. 파일 선택 화면에서 길게 누르거나 ‘선택’을 눌러 여러 책을 골라 주세요. 선택 방법은 기기의 파일 앱에 따라 다를 수 있습니다.
가져오는 동안 처리한 파일 수가 표시됩니다. 일부 파일을 가져오지 못해도 나머지는 계속 추가되며, 완료 후 실패한 파일 이름을 확인할 수 있습니다.
여러 파일을 가져온 뒤에는 새 묶음을 만들거나 기존 묶음에 추가할 수 있습니다. 이번에 새로 추가된 책이 선택되며, 다음 화면에서 제목과 순서를 확인하고 저장합니다. ‘각각 보관’을 누르면 개별 책으로 유지합니다.
책 카드의 더보기 메뉴에서 ‘표지 이미지 등록’ 또는 ‘표지 이미지 변경’을 선택하면 원하는 이미지를 표지로 쓸 수 있습니다.
표지는 JPG·PNG·WebP 이미지를 사용해 주세요. ‘표지 초기화’로 제목이 표시되는 기본 표지로 돌아갈 수 있습니다.
표지를 바꿔도 책 본문과 읽던 위치는 그대로 유지됩니다.

[장] 시집·소설 TXT에서 장 나누기
새 페이지에서 시작할 시나 회차의 제목 줄을 ‘[장] 제목’ 형식으로 작성하세요. 줄 맨 앞에 [장]을 쓰고, 공백 또는 탭 뒤에 제목을 넣습니다.
예를 들어 제목 줄에 ‘[장] 봄날’, 다음 줄부터 시 본문을 적고, 다음 시의 제목 줄에 ‘[장] 여름밤’을 적습니다. 소설은 ‘[장] 제1화’, ‘[장] 제2화’처럼 사용할 수 있습니다.
독서 화면에는 [장] 표식이 숨겨지고 제목과 본문이 보이며, ‘목차’에 제목이 등록됩니다.
페이지 넘김에서는 각 장이 새 페이지에서 시작합니다. 긴 시나 장은 여러 페이지에 걸칠 수 있고, 글자 크기를 키우면 페이지 수가 늘어날 수 있습니다. 두 페이지 화면에서는 왼쪽 또는 오른쪽의 다음 페이지에서 시작하므로 항상 왼쪽에서 시작하는 것은 아닙니다.
본문의 줄바꿈과 빈 줄은 유지됩니다. 첫 장 앞의 빈 줄만으로 빈 페이지를 만들지는 않습니다. 빈 줄만으로 장을 나누지는 않습니다.
연속 스크롤에서는 제목을 구분해 이어서 읽으며, 종이 페이지처럼 높이를 강제로 맞추지 않습니다.
제목 없는 [장], 본문 중간의 [장], 줄 앞에 공백이 있는 ‘ [장] 제목’은 장 구분으로 인식하지 않습니다. 표식이 없는 TXT는 기존처럼 이어서 읽습니다.
이 규칙은 기기에서 가져온 TXT와 다운로드한 TXT에 동일하게 적용됩니다. EPUB은 파일에 포함된 목차와 장 구성을 따릅니다.
이미 읽던 TXT에 장 표식을 추가하거나, 이전 앱에서 표식 그대로 읽던 파일을 새 방식으로 열면 본문 구성 변경 안내가 나올 수 있습니다. 이전 기록은 보존되며 새 목차에서 읽던 장을 찾아 이어 읽을 수 있습니다.

[장] 나누어진 책을 묶어서 정리하기
여러 파일로 나누어진 작품은 ‘책 묶음 만들기’로 한곳에 모을 수 있습니다.
서재의 책을 길게 누른 채 다른 책 위로 끌어 놓으면 묶음 만들기로 이어집니다. 기존 묶음 위에 놓으면 해당 묶음에 추가할 수 있습니다.
끌기가 어려우면 책 더보기 메뉴의 ‘책 묶음 만들기’ 또는 ‘묶음에 추가’를 이용하세요.
서재의 묶음에는 전체 권수와 완독 수가 표시됩니다. 묶음을 열면 현재 읽는 권과 전체 완독 현황을 확인할 수 있습니다. 완독은 사용자가 표시한 기록을 기준으로 하며 마지막 페이지에 도달해도 자동 표시하지 않습니다.
묶음 표지를 누르면 안에 있는 책 목록이 열립니다. 각 책을 따로 열어 읽고, 순서 변경 손잡이로 목록 순서를 조절할 수 있습니다.
이어 읽기 카드에는 개별 책의 표지를 먼저 표시하며, 개별 표지가 없으면 묶음 표지를 표시합니다. 둘 다 없으면 기본 표지가 표시됩니다. 넓은 화면과 좁은 화면 모두 동일합니다.
묶음 안의 책은 기본적으로 표지 없는 목록으로 표시됩니다. ‘묶음 안의 책 표지 표시’를 켜면 개별 표지도 볼 수 있습니다. 서재의 묶음 대표 표지는 그대로 유지됩니다.
새 묶음을 만들 때는 제목·회차 순으로 정렬됩니다. 기존 묶음의 순서를 바꾸고 싶으면 ‘제목·회차 순으로 정렬’을 누르세요. 직접 바꾼 순서는 자동으로 다시 정렬하지 않습니다.
묶음에 다음 책이 있으면 독서 화면에 ‘다음 권’이 표시됩니다. 제목을 확인하고 ‘열기’를 누르면 현재 위치를 저장한 뒤 묶음 순서의 다음 책을 엽니다. 마지막 페이지에서는 하단에 다음 권 제목과 ‘이어서 읽기’ 안내가 나타납니다. 본문 높이는 그대로이며 자동으로 다음 권을 열지 않습니다. 다음 책을 읽은 적이 있다면 그 책의 저장된 위치에서 시작합니다. 마지막 책에는 이 버튼이 표시되지 않습니다.
묶음은 파일을 하나로 합치는 기능이 아닙니다. 각 책의 본문과 독서 기록은 따로 유지됩니다.
잘못 넣은 책은 ‘묶음에서 꺼내기’로 빼면 됩니다. ‘묶음 관리’에서는 이름을 바꾸거나 묶음을 해제할 수 있습니다. 묶음 해제는 책을 삭제하지 않습니다.

[장] 책과 글꼴 다운로드
접힌 화면에서는 ‘도서·글꼴 다운로드’ 버튼을 누릅니다. 펼친 화면에서는 왼쪽 읽던 책 아래의 ‘도서·글꼴 다운로드’를 눌러 펼칩니다. 다운로드를 펼치면 읽던 책은 제목 한 줄로 접힙니다. 읽던 책 제목을 누르거나 다운로드를 접으면 이어 읽기 카드가 다시 나타납니다.
‘도서’ 또는 ‘글꼴’ 탭을 선택하고 각각의 검색창으로 찾을 수 있습니다. 도서는 제목·작가 검색과 공개된 도서의 분류를 함께 사용할 수 있습니다.
목록은 가나다순이며, 펼친 화면의 다운로드 목록은 오른쪽 서재와 따로 스크롤됩니다. 탭을 바꾸거나 이어 읽기와 다운로드 메뉴를 전환해도 다운로드 검색어와 스크롤 위치가 유지됩니다.
도서 목록에는 제목과 그 아래 글쓴이·분류가 표시됩니다. 제목을 누르면 설명·출처·이용 조건을 볼 수 있습니다. 도서와 글꼴 모두 이름 오른쪽의 다운로드 아이콘을 누릅니다. 다운로드 중에는 진행 표시가, 완료하면 체크 표시가 나타납니다.
글꼴 이름을 누르면 설명·출처·이용 조건을 볼 수 있습니다. 미리보기가 준비된 글꼴은 이름이 실제 글꼴 모양으로 표시되며, 미리보기가 없거나 불러오지 못하면 기본 글꼴로 표시됩니다.
내려받은 책은 내 서재에 추가됩니다. 글꼴은 책을 연 뒤 ‘독서 설정’ 맨 아래의 ‘글꼴’에서 선택합니다.
이미 열어 둔 독서 화면에 새 글꼴이 보이지 않으면 서재로 나갔다가 책을 다시 열어 주세요.
목록을 불러오거나 새 파일을 내려받을 때는 인터넷 연결이 필요합니다. 다운로드가 끝난 책과 글꼴은 오프라인에서도 사용할 수 있습니다.
제공 목록에서 나중에 항목이 내려가더라도 이미 기기에 내려받은 자료는 유지됩니다.

[장] 독서 화면 사용하기
페이지 넘김 방식에서는 ‘이전’·‘다음’ 버튼이나 화면 가장자리를 눌러 이동합니다.
본문 중앙을 누르면 독서 메뉴를 숨기거나 다시 표시할 수 있습니다.
‘목차’에서는 책에 포함된 장으로 이동합니다. 목차 구성은 책 파일에 따라 다릅니다.
책장 넘김 효과를 선택하면 가장자리를 누른 채 밀어 넘기는 동작도 사용할 수 있습니다.

[장] 본문 검색과 책갈피
독서 화면 상단의 ‘찾기’ 또는 돋보기 아이콘을 누르면 본문 검색과 책갈피 메뉴가 열립니다.
‘본문 검색’에서 단어나 문장을 입력하고 검색하면 이 책 안에서 찾습니다. 결과를 눌러 해당 위치로 이동합니다. ‘더 보기’로 계속 찾을 수 있으며, 한 번에 최대 500개까지 표시합니다. 결과가 많으면 검색어를 더 구체적으로 입력하세요. 인터넷 연결은 필요하지 않습니다.
‘현재 위치에 책갈피 추가’를 누르면 이름을 정해 저장합니다. ‘책갈피 목록’에서 다시 이동하거나 삭제할 수 있습니다. iOS에서는 목록을 옆으로 밀어 삭제하고, Android에서는 항목을 눌러 ‘삭제’를 선택합니다. 책마다 최대 100개까지 저장할 수 있습니다.
검색 결과·목차·책갈피로 이동한 뒤 하단의 되돌아가기 화살표를 누르면 이동 전 읽던 위치로 돌아갑니다. 이 이동 기록은 책을 닫으면 초기화되며 최근 20번의 이동을 보관합니다.
책갈피는 이 기기에 저장되며 서재 백업에도 포함됩니다. 본문 파일이 바뀌면 이전 내용의 책갈피를 새 내용에 자동 적용하지 않습니다.

[장] 독서 설정
독서 화면의 ‘독서 설정’에서 본문을 보며 읽기 환경을 조절합니다.
보기 설정은 이 기기의 모든 책에 공통으로 적용됩니다. 다른 책을 열거나 앱을 다시 실행해도 마지막으로 사용한 설정을 유지합니다. 읽던 위치는 책마다 따로 저장됩니다.

글자 크기: A−와 A+로 조절합니다.
배경: 밝게·종이색·어둡게 중 선택합니다.
읽기 방식: 페이지 넘김 또는 연속 스크롤을 선택합니다.
페이지 배치: 자동·한 페이지·두 페이지 중 선택합니다. 두 페이지는 본문을 표시할 너비가 충분할 때 적용됩니다.
두 페이지 화면의 중앙에는 페이지를 구분하는 은은한 선이 표시됩니다. 한 페이지와 연속 스크롤에서는 표시하지 않습니다.
페이지 전환 효과: 바로 넘기기 또는 책장 넘기기를 선택합니다.
줄간격: 기본·촘촘·보통·넉넉 중 선택합니다.
문단 간격: 기본·없음·보통·넓게 중 선택합니다. 빈 줄 자체를 삭제하는 기능은 아닙니다.
페이지 여백: 기본·좁게·보통·넓게 중 선택합니다. 두 페이지에서는 좌우 여백과 중앙 간격이 함께 바뀝니다.
줄·문단 간격의 ‘기본’은 책의 원래 스타일을 따릅니다. 간격을 직접 지정하면 EPUB의 출판사 문단 스타일 일부가 바뀔 수 있습니다.
글꼴: 맨 아래 목록에서 기본 글꼴이나 내려받은 글꼴을 선택합니다.

연속 스크롤에서는 페이지 배치와 페이지 전환 효과를 조작할 수 없습니다. 페이지 넘김으로 돌아오면 이전 선택을 다시 사용할 수 있습니다.
글자 크기나 화면 배치가 바뀌면 페이지 수와 문장이 보이는 화면 안 위치도 달라질 수 있습니다.

[장] 읽던 위치와 폴더블 화면
독서 위치는 자동으로 저장됩니다. 서재로 돌아온 뒤 ‘이어 읽기’로 계속 읽을 수 있습니다.
화면을 접거나 펼치고, 글자 크기나 글꼴을 바꾸면 읽던 문장을 기준으로 새 화면에 위치를 복원합니다.
같은 문장이 보이더라도 페이지 번호나 페이지 시작 부분은 이전과 다를 수 있습니다.
책 파일의 내용 자체가 바뀐 경우에는 이전 위치를 그대로 사용할 수 없어 확인 안내가 나올 수 있습니다.

[장] 개인정보와 광고 선택
첫 실행에서 비맞춤형 광고 또는 맞춤형 광고 허용을 선택합니다. 어느 쪽을 선택해도 독서는 계속 이용할 수 있습니다.
iOS의 추적 허가는 별도 권한입니다. 맞춤형 광고를 선택해도 추적을 허용하지 않으면 비맞춤형 광고가 적용됩니다.
서재 상단 ‘설정’ > ‘개인정보 및 광고’에서 선택을 변경하고 개인정보처리방침을 확인할 수 있습니다. 방침은 인터넷 없이도 볼 수 있습니다.
문의나 부적절한 광고 신고는 같은 메뉴에서 대표 메일 koofylab@gmail.com으로 보낼 수 있습니다. 책 본문이나 독서 기록은 자동 첨부하지 않습니다.

[장] 광고 없이 2시간 읽기
서재 상단의 ‘설정’에서 ‘광고 보고 2시간 광고 없이 읽기’를 선택합니다.
리워드 광고의 시청 완료 보상이 확인되면 서재·설정·독서 화면의 배너 광고가 2시간 동안 숨겨집니다. 중간에 닫은 것만으로는 보상이 지급되지 않습니다.
광고를 닫은 뒤 완료 확인이 늦게 도착하는 경우에도 확인된 보상은 적용됩니다.
숨김 중에는 광고가 차지하던 하단 공간도 사라져 본문을 더 넓게 볼 수 있습니다. 시간이 끝나면 광고 영역이 다시 나타납니다.
남은 시간은 앱 설정에서 확인합니다. 숨김 시간이 끝난 뒤 다시 시청할 수 있으며, 시간을 미리 누적하는 기능은 없습니다.
만료 시각은 기기에 저장되어 앱을 껐다 켜도 유지됩니다. 앱을 종료한 동안에도 2시간은 계속 흐릅니다.
인터넷 연결이나 광고 제공 상황에 따라 광고를 불러오지 못할 수 있습니다. 이 경우 잠시 후 다시 시도해 주세요.

[장] 책 삭제와 이전 기록
책 더보기에서 완독 표시를 바꾸거나 책을 삭제할 수 있습니다. 기본 샘플은 ‘서재에서 숨기기’로 정리합니다. 현재 숨긴 기본 샘플을 다시 표시하는 메뉴는 없습니다.
이전 앱 버전의 기록이 있다면 ‘이전 버전의 독서 기록’에서 보존된 기록과 북마크를 확인할 수 있습니다.
현재 본문과 위치가 확인되는 TXT 기록은 자동으로 옮겨집니다. 확인되지 않는 기록은 안내에 따라 문맥이나 목차로 읽던 곳을 찾아 주세요.
책·독서 기록·광고 숨김 시간은 기기 중심으로 관리됩니다. 앱 삭제나 앱 데이터 초기화 시 잃을 수 있으며 다른 기기로 자동 동기화되지 않습니다.

[장] 서재 백업과 복원
서재 상단 ‘설정’ > ‘서재 백업·복원’에서 ‘백업 파일 저장’을 누르고 파일 앱의 저장 위치를 선택합니다.
책 원본·표지·묶음과 순서·읽던 위치·책갈피·완독 표시·보기 설정을 .koofy.zip 파일 하나로 보관합니다. 다른 기기로 파일을 옮긴 뒤 ‘백업 파일 불러오기’에서 선택하고 복원할 수 있습니다.
복원은 현재 기기에 없는 책과 기록을 추가하는 방식입니다. 같은 책의 현재 기록과 기존 묶음 순서·보기 설정은 유지합니다. 처음 사용하는 기기에는 백업의 보기 설정을 적용합니다.
다운로드한 글꼴은 새 기기에서 다시 내려받아 주세요. 해당 글꼴이 없으면 기본 글꼴로 읽습니다. 광고 숨김 시간과 광고 동의 정보는 백업하지 않습니다.
원본과 표지 등의 합계 기준으로 한 번에 100MB까지 지원합니다. 책 원본을 찾을 수 없거나 백업 파일이 손상되면 안내가 표시됩니다. 오류가 발생한 복원은 같은 백업 파일로 다시 시도할 수 있습니다.
백업에는 책 본문이 포함됩니다. 본인이 관리하는 저장 위치에 보관하고, 앱을 삭제하기 전에는 앱 바깥에 저장했는지 확인해 주세요. 자동 동기화 기능은 아닙니다.

[장] 책 읽어주기
독서 화면 오른쪽 위 독서 설정 아래의 ▶ 버튼을 누르면 현재 보이는 위치부터 읽습니다. 재생 중에는 Ⅱ 버튼으로 잠시 멈추고 다시 이어 들을 수 있습니다.
앱이 기기에 설치된 로컬 한국어 음성을 사용합니다. 음성 합성을 위해 책 본문을 서버로 보내지 않습니다. 인터넷이 필요한 음성은 선택하지 않습니다. 기기에 따라 사용 가능한 목소리와 음질이 다릅니다.
‘독서 설정 → 듣기 설정’ 또는 재생 버튼을 길게 눌러 목소리·읽기 속도·취침 타이머를 바꿀 수 있습니다. 음성을 선택하고 ‘미리 듣기’로 확인하세요. 목소리와 속도는 다른 책에도 적용됩니다.
한국어 음성이 없다면 Android는 듣기 설정의 ‘기기 음성 다운로드’, iPhone은 기기 설정의 ‘손쉬운 사용 → 읽기 및 말하기(또는 콘텐츠 말하기) → 음성 → 한국어’에서 음성을 설치한 후 독서 화면을 다시 열어 주세요.
듣는 동안 하단 메뉴의 이전 문장·다음 문장 버튼을 사용할 수 있습니다. ‘음성을 따라 페이지 이동’을 켜면 읽는 문장을 따라 본문이 이동합니다.
홈 화면·다른 앱·서재로 이동하거나 화면을 잠그면 듣기가 멈춥니다. 전화·이어폰 분리·광고 클릭 때도 멈추며, 돌아와도 자동으로 재생하지 않습니다. 배너가 보이는 것만으로는 멈추지 않습니다.
직접 페이지나 목차·검색 결과로 이동하면 듣기가 멈추며, 다음 재생은 새 위치에서 시작합니다. 글자 크기 변경이나 화면 회전·접힘 때는 잠시 멈추고 듣던 문장 위치를 유지합니다.
듣던 위치는 눈으로 읽던 위치와 별도로 기기에 저장합니다. ‘듣기 설정 → 저장된 듣던 위치부터 재생’으로 이어 들을 수 있습니다. 본문 파일이 바뀐 경우 이전 음성 위치를 사용하지 않습니다.
책 끝에서는 멈추며 다음 묶음도서로 자동 이동하지 않습니다. 음성 설정과 듣던 위치는 현재 서재 백업 파일에는 포함되지 않습니다.

[장] 지원 파일과 아직 없는 기능
Android·iOS에서 DRM 없는 리플로우 EPUB과 TXT를 읽을 수 있습니다.
기기에서 직접 가져오는 TXT는 UTF-8 또는 BOM이 있는 UTF-16으로 저장해 주세요. CP949·EUC-KR 파일은 UTF-8로 변환한 뒤 가져옵니다.
PDF·만화 전용 파일·DRM으로 보호된 전자책·고정 레이아웃 EPUB은 현재 지원하지 않습니다.
메모와 기기 간 자동 동기화는 아직 제공하지 않습니다. 서재 검색은 책 제목과 작가를, 독서 화면의 본문 검색은 현재 책의 내용을 찾습니다.
